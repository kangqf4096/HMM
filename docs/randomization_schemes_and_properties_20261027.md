# 不同随机化方案及其性质：比较、选型与测量

日期：2026-10-27。范围：LLM 文本水印中“随机量放在哪里”的几种典型方案，以及它们在零分布、备择分布、生成质量、密钥作用和检测信息上的差别。本文是工程/统计比较，不是完整综述；具体论文的实现细节以原文为准。综述背景见 [语义向量水印与密钥_文献综述.md](../../语义向量水印与密钥_文献综述.md)，Gumbel-max 备择分布的完整性质见 [标准密钥方案下的备择分布性质](alternative_distribution_properties_20261027.md)。

---

## 0. 比较轴

判断一个随机化方案，至少要看八件事：

1. **随机量注入点**：改 logits、改 Gumbel 噪声、改逆 CDF 分位数、改接受/拒绝区域，还是改词表划分。
2. **零假设枢轴**：是什么、是否精确 Uniform/已知、是否需要模型。
3. **备择分布**：依赖 \(P_t\)、依赖 key、依赖语义码，还是与上下文无关。
4. **生成是否无损**：token 边际是否仍为 \(P_t\)。
5. **key/secret 的作用**：划分词表、派生 seed、决定噪声、决定区域，还是只做认证。
6. **检测需要什么信息**：key、\(P_t\)、embedding、分区表、模型访问。
7. **熵/集中度如何影响信号**：是 \(S_2\)、绿名单质量、区域质量，还是 \(U'\) 的偏置。
8. **主要失败模式**：质量损失、零分布失准、key 不稳定、模型失配、编辑后失效、多重检验。

---

## 1. 方案逐个

### 1.1 KGW 绿名单（logit bias）

**机制**：用 key（和前缀）把词表划成绿/红名单，对绿 token 的 logits 加 \(\delta\)，再采样。

**零分布**：给定前缀，绿名单由 key 决定，与当前 token 独立；绿指示近似 \(\mathrm{Bern}(\gamma)\)，\(\gamma\) 是绿名单比例。计数型 z-test 不需要模型访问。

**备择**：绿 token 概率高于 \(\gamma\)；提升幅度取决于 \(P_t\) 在绿名单上的质量、\(\delta\)、温度和截断。备择依赖 \(P_t\)，但没有 Gumbel-max 那样的闭式 \(f_{1,P}\)。

**质量**：**有损**。加 \(\delta\) 改变 token 分布；\(\delta\) 越大，水印越强，质量/多样性损失越大。不是 distortion-free。

**key 作用**：决定绿/红划分；key 熵和划分方式影响安全性与可检测性。

**检测信息**：key/绿名单；不需要 \(P_t\)。这是它最大的工程优势。

**熵/集中度**：信号取决于“绿名单在 \(P_t\) 下的质量”和 \(\delta\)，不是 \(S_2\)。若 \(P_t\) 很集中且高概率 token 恰好不在绿名单，信号可能很弱；若集中在绿名单，信号强。

**主要失败**：质量损失；对语义保持攻击/复述不鲁棒；重复上下文/固定划分的依赖；绿名单比例 \(\gamma\) 的校准。

---

### 1.2 Gumbel-max（标准密钥方案）

**机制**：key/上下文派生 \(U_{t,w}\)，\(X_t=\arg\max_w \log U_{t,w}/P_{t,w}\)，枢轴 \(Y_t=U_{t,X_t}\)。

**零分布**：\(Y_t\sim\mathrm{Unif}(0,1)\)，精确（理想独立 Uniform + key 与当前 token 条件独立）。检测端若知道 \(P_t\)，可算精确枢轴；不知道 \(P_t\) 时只能用近似/模型无关统计量。

**备择**：

\[
F_{1,P}(y)=\sum_w P_w y^{1/P_w},\qquad
f_{1,P}(y)=\sum_w y^{1/P_w-1}.
\]

依赖 \(P_t\) 的整个概率谱；已知 \(P_t\) 时可解析计算。

**质量**：**无损**（Gumbel-max 保边际）；前提是 \(U\) iid Uniform、PRF 无偏、Gumbel-max 实现正确（top-p 截断等要一致）。

**key 作用**：派生每步随机向量；固定 key/上下文复用时会产生依赖。

**检测信息**：\(P_t\) + key。没有 \(P_t\) 时，可用“token 是否赢家”的近似统计量，但功效/校准会弱。

**熵/集中度**：\(S_2=\sum P_w^2\) 决定 \(E[-\log Y]\)；\(S_3\) 决定方差；\(H\) 给 KL 上界。越集中，\(S_2\to1\)，信号越弱；均匀 \(K\) 个 token 时 KL \(=\log K-1+1/K\)。

**主要失败**：模型/温度/top-p 不一致导致 \(P_t^{\mathrm{eval}}\ne P_t^{\mathrm{gen}}\)；固定 key/上下文复用导致联合依赖；弱信号（近确定性 \(P\)）不可辨识；PRF 有偏破坏边际。

---

### 1.3 逆 CDF + 有偏 \(U\)

**机制**：key 派生 \(U'_t\)，令 \(X_t=F_{P_t}^{-1}(U'_t)\)；\(U'_t\) 不是 Uniform，而是偏向某个区域（如 \(U'=U^\beta\)）。

**零分布**：无水印时 \(X_t\sim P_t\)，\(Y_t=F_{P_t}(X_t)\sim\mathrm{Unif}(0,1)\)。

**备择**：\(Y_t=U'_t\)，其分布是 \(U'\) 的分布（如 Beta），**与 \(P_t\) 无关**。这是它和 Gumbel-max 最大的区别：备择上下文无关，但代价是 token 边际不再是 \(P_t\)。

**质量**：**有损**。\(U'\) 非均匀，\(X_t=F^{-1}(U')\) 的边际偏离 \(P_t\)；\(D_{\mathrm{KL}}(U'\Vert\mathrm{Unif})\) 就是质量损失的度量（在分位数空间）。

**key 作用**：决定 \(U'\) 的偏置；key 稳定性影响备择的复现，但不影响零分布。

**检测信息**：\(P_t\)（算 \(F_{P_t}\)）+ key。若 \(P_t\) 错，枢轴 \(Y_t\) 也错。

**熵/集中度**：备择由 \(U'\) 的偏置决定，**与 \(P_t\) 的集中度无关**；\(P_t\) 只影响质量损失和检测端计算 \(F\) 的难度。

**主要失败**：质量损失；偏置太大时文本明显不自然；\(P_t\) 误差直接污染枢轴；攻击者知道 key 后可以去除偏置。

**适用**：当你想要“备择分布上下文无关、零分布精确”，且能接受质量损失时；也适合作为理论对照/模拟基线。

---

### 1.4 ExpMin / SynthID / WaterMax（mark module 层）

这三类是“采样/打分模块”，不是密钥方案；它们可以和上下文哈希或语义 key 组合。按综述和原论文的描述，它们的共同结构是：

- key/上下文派生逐位置随机量；
- 用某种指数竞争、tournament 或 max-normal 规则选 token；
- 检测端把逐位置分数聚合（和、最大值、尾计数等）。

**零分布**：在理想随机量假设下通常可解析/可校准；具体是否精确 Uniform，取决于模块和实现。

**备择**：依赖 \(P_t\) 和模块规则；通常没有 Gumbel-max 那样统一的 \(f_{1,P}\) 闭式，需要按模块推导或模拟。

**质量**：**混合**。有的模块设计为 distortion-free，有的会改变边际；不能一概而论。需要看原论文的“无偏/保分布”声明及其假设。

**key 作用**：决定随机量/ tournament 的随机性；重复上下文可能复用。

**检测信息**：规则/key；有的需要 \(P_t\)，有的只需要分数。

**熵/集中度**：模块特定；通常与 \(P_t\) 的集中度、候选集大小、分数函数有关。

**主要失败**：实现细节多、复现难；不同模块的 null/alt 不能混用；质量/鲁棒性/计算开销的取舍不同。

**本文的处理**：在对比表里把它们归为“mark module 层”，不强行给统一公式；如果项目要选其中一个，必须单独推导它的 null/alt，并做与 Gumbel-max 的同条件对比。

---

### 1.5 语义拒绝采样（SemStamp / k-SemStamp / SemaMark / SimMark / CN121881315A）

**机制**：语义编码器把句子/上下文映射成码；key 决定 valid 区/相似度区间/聚类；生成时反复采样，直到新句落入 valid 区（或满足 margin/相似度区间）。

**零分布**：valid 指示近似 \(\mathrm{Bern}(\gamma)\)；若划分对数据分布是测度保持的、且码只依赖前缀，才近似精确。LSH/聚类划分对真实句向量分布通常不是均匀的，\(\gamma\) 只是码空间比例；边界/margin 还会引入 Q-offset 等修正。句级码若含当前句，会破坏条件独立。

**备择**：接受概率取决于 \(P_t\) 在 valid 区的质量、margin、句长；条件性强，pooled 经验分布只是条件加权边际。

**质量**：**有损**。接受的是 \(P(\cdot\mid\text{落入 valid 区})\)，不是 \(P(\cdot)\)；semantic narrowing、多样性下降、重采样成本。不是 distortion-free。

**key 作用**：决定 valid 区/聚类/区间；码熵通常较低（LSH 位数、簇数、区间数）。

**检测信息**：语义编码器 + 分区/区间 + key；不需要 \(P_t\)（这是优点），但需要编码器一致。

**熵/集中度**：信号取决于 \(P_t\) 在 valid 区的质量与区域几何，不是 \(S_2\)；区域越大，接受越容易但信号越弱。

**主要失败**：质量损失；边界跳变；码不稳定/碰撞；零分布近似；复述/跨语言 BER；拒绝采样成本。

---

### 1.6 语义 key + Gumbel-max（SimKey 风格）

**机制**：语义编码器把前缀编码成稳定码 \(w_t\)；fuzzy extractor/secure sketch 把 \(w_t\) 变成稳定、伪均匀的 key \(R_t\)；PRF 生成 Gumbel 噪声；Gumbel-max 采样。

**零分布**：key 只依赖前缀；给定前缀 key 固定，\(Y_t\sim\mathrm{Unif}\)，精确（理想 Uniform）。key 错配通常只伤功效，不伤零分布。

**备择**：\(f_{1,P_t}\)，与标准 Gumbel-max 相同；语义部分只改变 key 的派生，不改变 \(P_t\) 进入备择的方式。

**质量**：**无损**（若 PRF 白化、Gumbel-max 正确）。语义 key 本身不改变边际。

**key 作用**：语义码 → 稳定码 → ECC/secure sketch → 隐私放大 → PRF。稳定性由 ECC 负责，不由 PRF 负责；PRF 的 avalanche 是故意的。

**检测信息**：\(P_t\) + 语义编码器/helper + key。可以枚举 idx/salt 找回耦合，但要做多重检验校正。

**熵/集中度**：备择的 \(S_2/S_3\) 与标准 Gumbel-max 相同；另加 key 的 BER/熵。语义码的 min-entropy 决定 key 长度和安全性。

**主要失败**：语义码不稳定/碰撞；fuzzy extractor 的 helper 泄露；key 枚举的多重检验；编码器/模型版本不一致；PRF 有偏。

**适用**：项目要“生成无损 + 零分布精确 + 语义绑定/抗移植”时的首选组合。

---

### 1.7 固定/Unigram 划分（基线）

**机制**：key 固定划分词表，不依赖逐步上下文；对某组 token 加权/选择。

**零分布**：给定划分，组指示近似 \(\mathrm{Bern}(\gamma)\)；精确性取决于划分与 key 独立性。

**备择**：依赖 \(P_t\) 在固定组的质量；没有上下文自适应。

**质量**：通常有损（若加权）；若只做选择/拒绝，也可能有损。

**key 作用**：固定分组；key 熵/分组方式决定安全性。

**检测信息**：划分/key；不需要模型。

**熵/集中度**：信号取决于固定组在 \(P_t\) 下的质量；对上下文变化不敏感，但对语义攻击/复述不鲁棒。

**主要失败**：质量损失；上下文无关导致语义攻击容易；重复/固定划分的统计依赖。

| KGW 绿名单 | 改 logits（绿名单加 \(\delta\)） | 绿指示 \(\sim\mathrm{Bern}(\gamma)\) | 绿概率升高，依赖 \(P\) 的绿名单质量 | 否 | 划分词表 | key/绿名单；无需 \(P_t\) | 绿名单质量，不是 \(S_2\) | 质量损失、复述不鲁棒 |

## 3. 熵/集中度在各方案中的作用

| 方案 | 决定信号强弱的主要量 | 熵的作用 |
|---|---|---|
| KGW | 绿名单在 \(P_t\) 下的质量、\(\delta\) | 间接；集中分布可能让绿名单质量偏差更关键 |
| Gumbel-max | \(S_2=\sum P_w^2\)（均值）、\(S_3\)（方差） | \(H(P)\) 给 KL 上界；单独不足以决定 \(f_1\) |
| 逆 CDF 有偏 \(U\) | \(U'\) 的偏置 | \(P\) 的熵只影响质量损失，不影响枢轴备择 |
| ExpMin/SynthID/WaterMax | 模块的分数分布 | 模块特定；需按论文/模拟 |
| 语义拒绝采样 | \(P_t\) 在 valid 区的质量、区域几何 | 间接；区域大小比熵更直接 |
| 语义 key + Gumbel-max | \(S_2/S_3\) + key 稳定性 | 同 Gumbel-max；另加语义码的 min-entropy |

一句话：**不要用一个统一的“熵”指标比较所有方案**。对 Gumbel-max，用 \(S_2/S_3\)；对 KGW，用绿名单质量；对逆 CDF，用 \(U'\) 的偏置；对语义拒绝，用区域质量。

## 4. 选型指南

| 目标 | 首选 | 代价/注意 |
|---|---|---|
| **生成质量优先** | Gumbel-max；语义绑定则语义 key + Gumbel-max | 需要 \(P_t\) 才能精确检测；key 稳定性/熵 |
| **检测端无模型访问** | KGW、固定划分、语义拒绝 | 质量损失/零分布近似/语义鲁棒性差 |
| **备择分布上下文无关** | 逆 CDF + 有偏 \(U\) | 质量损失；\(P_t\) 误差污染枢轴 |
| **定位 + 条件 HMM** | Gumbel-max + \(P_t\)；无 \(P_t\) 时按 \(S_2/S_3\) 分层 | \(P_t^{\mathrm{gen}}\) 与 \(P_t^{\mathrm{eval}}\) 的差距 |
| **编辑/复述鲁棒** | 语义 key + fuzzy extractor + Gumbel-max | key BER、helper 泄露、枚举多重检验 |
| **多比特载荷** | 语义码/桶编码 + ECC | 不在本文范围；BER 是核心 |
| **理论对照/模拟** | 逆 CDF 有偏 \(U\)（上下文无关备择）+ Gumbel-max（无损备择） | 两者代表三难的两个角 |

## 5. 实验矩阵

| 维度 | 测什么 | 怎么测 |
|---|---|---|
| 质量 | perplexity、多样性、self-BLEU、重复率 | 同 prompt 下水印 vs 无水印 |
| 零分布 | 枢轴是否 Uniform；any-FP | 独立 null 文档；KS/直方图；按文档校准 |
| 备择 | PIT/KS vs 解析 \(f_1\)；\(S_2/S_3\) 分组 | 纯水印留出文章；记录 \(P_t\) |
| 功效 | KL、达到给定 power 所需 token 数 | 模拟/真实模型 |
| key | BER/GAR、熵、碰撞、helper 泄露 | 复述/翻译；NIST/最小熵估计 |
| 编辑 | \(P_t^{\mathrm{gen}}\) vs \(P_t^{\mathrm{eval}}\) 的 TV；seed vs \(P\) 失配 | 保留 token 的 teacher forcing |
| 定位 | IoU/F1、any-FP、后验可靠性 | 混合文本；独立 null |
| 成本 | 运行时间、模型访问、内存 | 生成/检测分开报告 |

## 6. 常见误读

1. **“distortion-free = 零分布精确”**：不是。Gumbel-max 两者都有；逆 CDF 有偏 \(U\) 零分布精确但有损；KGW 零分布精确但有损。
2. **“key 派生 = 与 token 独立”**：只在给定前缀下条件独立；边际相关是共享上下文造成的，无害。
3. **“熵越大信号越强”**：只在主序意义下严格；Gumbel-max 用 \(S_2/S_3\)，其他方案用别的量。
4. **“经验 \(f_1\) 可以跨语料/跨编辑迁移”**：只在同一总体/同一 \(Q_1\) 下成立；否则是偏差。
5. **“语义方法一定鲁棒”**：语义码会碰撞、会跳变；拒绝采样还有质量损失。
6. **“PRF 可以既白化又稳定”**：不能；稳定性靠稳定码 + ECC/secure sketch。
7. **“Gumbel-max 一定强”**：\(P\) 接近点质量时没有可辨识信号；应 abstain。
8. **“CDF 接近 = 密度比接近”**：不保证；尾部和 log 密度比可能更敏感。
