## 对照论文、作者公开代码与本地实现

| 环节 | 本地实现与核查结论 |
|---|---|
| EMS 分数 | log Y+1，与论文式 (2) 一致；值越大越支持水印 |
| 窗口随机化 | 以 null 分数≥观测分数计数，与式 (8) 的方向一致；T=999，加一修正 |
| KS 扫描 | 按式 (9) 的加权两样本经验 CDF 差；计数恒等式与直接计算一致 |
| 区间自助 | 按式 (10) 比较复制序列的最大 KS 与观测最大 KS；以 B 为块长、有放回抽块、拼接后截长 |
| NOT | 在 p̃<ζ 的候选中选最窄区间，移除包含所选切点的候选，与 Algorithm 1 的集合操作一致 |
| 段检验 | −Σlog Y 的 Gamma(L,1) 下尾检验；高 Y 应给出较小检验值，方向正确；标签条件为 p_segment<c，等价于 score>τ |

论文式 (8)–(10) 与 Algorithm 1 已回到本地 PDF 第 5–7 页目视核对。整数类型在长度≤180 时使用 int16，平方数量级不超过 32400；更长时改用 int32。实际 n_eff=124，不存在这一计算路径上的 int16 溢出。

但当前实现并不是作者发布脚本的逐项复现，以下差异需明示。

| 项目 | 论文/作者脚本 | 本轮适配 |
|---|---|---|
| 原文协议与对齐 | 固定钥匙序列，窗口对钥匙位置扫描 | 上下文派生密钥，直接使用重算的同位置枢轴；不做钥匙扫描 |
| 零复制序列 | 重新随机化钥匙 | iid U(0,1) 序列；同一复制内共用，但重复上下文/token 的相关结构没有专门保留 |
| 长度与窗口 | 论文主实验 m=500、B=20；作者脚本只保留完整内部窗口 | 本轮 n_eff=124；B 从 6/10/14/20 选；边缘使用截短窗口 |
| 最短候选区间 | 论文主实验 50 | 2.5B，入选 B=6 时约 15 |
| 自助实现细节 | 论文写有放回；当前公开 R/Python 脚本却默认无放回抽块，并写死块长 10、T′=999 | 本轮按预先方案有放回，块长=B、T′=1999 |
| ζ 的严格性 | Algorithm 1 写 p̃<ζ；作者 5-not.R 用≤ | 本轮用<，与 Algorithm 1 和本轮方案一致 |
| 输出与指标 | Algorithm 1 输出切点，论文主要报 Rand index | 再加本项目段检验标签，以支持 IoU 和文档 any-FP |

作者 README 也注明 Python SeedBS 输出不保证与 R 相同。公开代码细节与论文描述存在差异，不能仅凭这些差异判定本轮代码错误；本轮遵循的是已经写定的适配方案。差异对性能的影响没有在本次 test 上重新调参量化。

## 切分与标签的机制诊断

| 场景（各 40 篇 test） | 实际 seedbs IoU | 保留检出切分、用真值选择最优段标签的 IoU 上限 | 提供真值边界、保留原段检验与冻结阈值的 IoU |
|---|---:|---:|---:|
| full_wm | 0.8770 | 1.0000 | 1.0000 |
| switch | 0.8051 | 0.9109 | 1.0000 |
| resample_0.1 | 0.5844 | 0.6992 | 0.8383 |
| resample_0.3 | 0.2156 | 0.4328 | 0.5320 |

保留检出切分时，最优段标签列是使用真值计算的不可部署上限。对每段统计水印数和非水印数，按水印比例排序，比较各个前缀作为正段时的 IoU，得到能达到的最大值。它证明的是这次固定切分丢失了多少可分辨结构，不用于提出新的实际方法。

提供真值边界的列使用实际 Y、原 Gamma 段检验以及同一个冻结阈值 c，不再执行切换点检测；它也使用了真值，且没有重新校准其 null 误报。因此两列仅作机制诊断，不能当作经过同一误报控制的新 baseline，也不能将它们的差直接作可加的因果贡献。

full_wm 的真正切点数为零，但现有结果平均切出 5.075 个点；标签阈值会拒绝部分被切短的真水印段，使 recall/IoU 降到 0.8770。提供真值边界后所有 40 篇为 1，说明额外切分与后续段检验之间确有性能损失。

switch 的现有切分即使配上最有利的真值标签，上限为 0.9109，实际为 0.8051，说明切点位置与段标签判定都有限制。resample_0.1 的现有切分上限为 0.6992，低于 PD hist200 的 0.8026；resample_0.3 的现有切分上限为 0.4328，低于 PD hist200 的 0.4743。仅调标签阈值无法在这些固定切分上消除差距。

## 当前真值与窗口尺度的关系

| 场景 | 真水印连续段中位长度 | 平均长度 | 短于 7 个位置的段比例 | 短于 15 个位置的段比例 |
|---|---:|---:|---:|---:|
| full_wm | 124.0 | 124.00 | 0.0% | 0.0% |
| switch | 64.0 | 64.00 | 0.0% | 0.0% |
| resample_0.1 | 8.0 | 11.11 | 42.6% | 75.2% |
| resample_0.3 | 2.0 | 5.47 | 84.9% | 94.5% |

本项目把被编辑位置及其后最多 4 个上下文位置的真值置零，要求定位剩余的水印耦合；它会在原水印块里产生细碎孔洞。B=6 的内部窗口实际含 7 个位置，最短候选区间约 15。最短候选区间不等于强制最短检出段长，但这种窗口和区间尺度限制了分辨细碎变化的能力。尤其 30% 替换场景的真水印段中位长度只有 2，大多数真水印段比窗口短。HMM 逐位置利用拟合发射分布，再结合连续性，目标与信息利用方式不同。

## 结论范围与后续处理

本轮结果可以支持：在当前存活耦合真值、训练数据与校准流程下，主表四格的 IoU 高于本项目 seedbs 适配实现。不能据此声称严格复现并超越论文原算法。HMM 另有 100 篇纯水印和 50 篇 mixed_cal 训练数据；seedbs 不用这些拟合密度与 A。固定 τ 下 PD hist200 的实际 any-FP=5.75%，seedbs=3.00%，也并非严格相同的实际误报水平。

未修改 seedbs 算法、参数或本轮正式结果。没有发现必须修正的执行错误；如要研究更强的段标签、短段处理或与作者原代码一致的配置，需作为另一个明确记录的方案，不能在本次已看的 test 上挑到最有利设置后替换原 baseline。
