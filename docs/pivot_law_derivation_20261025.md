# Gumbel 枢轴分布与模型概率：解析关系、边缘化及失配

日期：2026-10-25。承接 [零假设与密钥笔记](watermark_hypotheses_and_keys_20261025.md)。以下从已缓存论文的 Gumbel-max 备择公式推导，不重复联网搜索。标为“推导”的公式是本次数学分析，不声称是新的文献贡献。

## 结论与适用边界

1. 条件性可以解析描述：备择分布由下一词分布 P 的概率质量谱决定；不只与某一个熵或 KL 数值有关。
2. X=-log Y 的全部正整数阶矩与 P 的概率幂和精确对应，特别是 E[X|P]=sum p²。这提供了直接可测的诊断量。
3. 若确实拿到生成时的完整 P，就能直接算每步备择 CDF/密度，无需估计各类上下文的概率。
4. 若只需要同一总体的平均备择分布，代表性的纯水印样本足以估计它，不需要逐项估计上下文混合权重。
5. 当前统一发射 HMM 比“估计平均分布”要求更强：总体构成改变、编辑选择、持久的信号强弱状态和密度比误差都可能影响定位与比例估计。

以下所有连续分布恒等式都在论文的理想模型下成立：有限词表、U_w 独立且均匀、P 在当前随机向量产生前确定，并与当前随机向量独立。p=0 的坐标不参加求和。固定密钥、完整 prompt 和计算过程时，实际程序可完全确定；不能把重复运行同一个 prompt 视为重复抽取这些连续分布。真实协议的重复上下文是另一项需要独立检查的失配。

## 1. 从指数竞争得到完整条件分布

令 E_w=-log U_w，则 E_w~Exp(1)。Gumbel-max 选择

\[
W=\arg\min_w T_w,\qquad T_w=E_w/p_w\sim\operatorname{Exp}(p_w).
\]

由于 sum p_w=1，最小值 T=min T_w~Exp(1)，且 T 与赢家 W 独立，Pr(W=w)=p_w。选中枢轴 Y=U_W 满足

\[
X:=-\log Y=p_W T.
\tag{1}
\]

因此：

\[
Y\mid(W=w,P)\sim\operatorname{Beta}(1/p_w,1),
\]

\[
F_{1,P}(y)=\sum_w p_w y^{1/p_w},\qquad
f_{1,P}(y)=\sum_w y^{1/p_w-1},\quad 0<y<1.
\tag{2}
\]

式 (2) 是统计框架论文 Lemma 3.1（PDF 第 13 页）的已知公式。式 (1) 给出了直接的生成表示：先以概率 p_w 选取一个概率质量 p_W，再用独立 Exp(1) 缩放它。故分布仅依赖概率数值及重数，不依赖 token 名称。重排词表坐标不会改变枢轴分布。

## 2. 与集中程度、熵和 KL 的解析关系

### 2.1 概率幂和给出全部矩

对整数 k>=1，利用 Exp(1) 的 k 阶矩为 k!：

\[
\boxed{\mathbb E[X^k\mid P]=k!\sum_w p_w^{k+1}.}
\tag{3}
\]

尤其是，记 S_r(P)=sum p_w^r，

\[
\mathbb E[-\log Y\mid P]=S_2(P),\qquad
\operatorname{Var}(-\log Y\mid P)=2S_3(P)-S_2(P)^2.
\tag{4}
\]

S2 是两次独立 token 抽样相等的概率，也称碰撞概率。它与二阶 Renyi 熵满足 H2(P)=-log S2(P)，常用有效词表大小为 1/S2(P)。零假设下 X~Exp(1)，E0[X]=1，因此 log 得分的均值间隔为 1-S2(P)。这比先泛泛地用某一种 KL 更直接对应当前水印的信号强弱。

另一个可用恒等式，对 a>=0：

\[
\mathbb E[Y^a\mid P]=\sum_w\frac{p_w}{1+a p_w}.
\tag{5}
\]

同一个 S2 不能确定整个备择。例如

\[
P=(1/2,1/4,1/4),\qquad Q=(5/12,5/12,1/6)
\]

都有 S2=3/8，但 S3 分别为 5/32 与 43/288，故 Var(X) 分别为 11/64 与 91/576，CDF 也不相同。测量 S2 适合解释主要信号强弱，涉及似然比和尾部阈值时仍需更完整的质量谱信息。

### 2.2 熵给出枢轴 KL 的上界

以 f0(y)=1 为参照，水印枢轴的平均 log 似然比是

\[
D_{\rm KL}(f_{1,P}\Vert f_0)=\int_0^1 f_{1,P}(y)\log f_{1,P}(y)\,dy.
\]

给定 W=w，Beta(1/p_w,1) 到均匀分布的 KL 为

\[
-\log p_w-1+p_w.
\]

按 p_w 加权，使用 KL 分解，得到本次推导：

\[
\boxed{
H(P)-1+S_2(P)
=D_{\rm KL}(f_{1,P}\Vert f_0)+I(W;Y\mid P).
}
\tag{6}
\]

因此

\[
0\le D_{\rm KL}(f_{1,P}\Vert f_0)\le H(P)-1+S_2(P).
\tag{7}
\]

所有对数均为自然对数。式 (6) 里的互信息按水印分布计算；证明中比较的联合参照分布是 W~P、Y~U(0,1) 且二者独立。这里没有假定现实人类文本一定按同一个 P 生成。

若 P 在 K 个 token 上均匀，则 Y~Beta(K,1)，I(W;Y|P)=0，精确得到

\[
D_{\rm KL}(f_{1,P}\Vert f_0)=\log K-1+1/K.
\tag{8}
\]

这说明 token 熵与水印信息量确有解析联系，但两者不是同一个 KL，也不能用一个 Shannon 熵数值恢复完整 f1。若词表大小固定为 V，D_KL(P||Uniform(V))=log V-H(P) 只是 H(P) 的另一种写法，不能额外揭示概率质量谱。

### 2.3 “更分散则更强”有严格但有限定的表述

固定 0<y<1，令 a=-log y，phi(p)=p exp(-a/p)，并以连续极限定义 phi(0)=0。可计算

\[
\phi''(p)=a^2 p^{-3}e^{-a/p}\ge0.
\]

因此 F1,P(y)=sum phi(p_w) 是 Schur 凸函数：若 P 在主序意义下比 Q 更集中，则

\[
F_{1,P}(y)\ge F_{1,Q}(y)\quad\text{对所有 }y.
\tag{9}
\]

也就是更分散的概率谱使 Y 在一阶随机序意义下更靠近 1。该结论适用于可按主序比较的分布；不能仅凭任意两分布的熵大小，就断言其所有尾部和全部检测指标都同序。

还有一项稳定结构：式 (2) 中每个指数 1/p_w-1 都非负，因此 f1,P(y) 随 y 非递减；任意条件混合后的平均密度也非递减。故以均匀 null 为参照，各条件下按 Y 由大到小的似然比排序方向一致。不同条件的似然比数值、过 1 的位置和最优阈值仍会不同；这项排序结构不保证统一发射的后验准确，也不保证 HMM 联合定位的排序不变。

## 3. 条件性是否意味着对小扰动极端敏感？

对 P、Q 使用共同词表，并令 TV(P,Q)=sum|p_w-q_w|/2。仍用上面的 phi，

\[
\phi'(p)=e^{-a/p}(1+a/p)\in[0,1].
\]

沿 P、Q 间的线段积分，又因各坐标差的和为零，可得

\[
\boxed{\sup_{0\le y\le1}|F_{1,P}(y)-F_{1,Q}(y)|\le\operatorname{TV}(P,Q).}
\tag{10}
\]

这是当前推导的 CDF 稳定性界，不是“对所有文本编辑都有界”：

- 若一次扰动只轻微改变 P，那么备择 CDF 也只会轻微改变。
- 上下文哈希使某次 U 的实现值大幅变化，不等于它使理想备择分布大幅变化；后者由 P 的概率谱决定。
- 少量文本编辑未必只轻微改变 LLM 的 P，需实测生成历史与最终历史下的模型概率差异。
- CDF 接近不保证逐点密度、密度比或 log 密度比接近。尤其在尾部、小概率区和接近零的估计密度处，HMM 使用的 log 发射比可能更敏感。
- 原始 P 接近点质量时，f1 本来就接近 f0，问题是信息量不足；这不等于估计方法本身不稳定。

## 4. 放弃模型无关后，可以得到什么？

### 4.1 拿到真实生成 P：逐位置备择可直接计算

如果掌握生成时的模型、完整原始 prompt/前缀、温度和所有 logit 处理，就可在每步采样前取得 P_t，然后用式 (2) 直接得到 f1,P_t、F1,P_t。

这条路线不需要知道各类上下文的总体出现概率，因为当前条件 P_t 本身可用。可在生成时保存 P_t 的摘要及预设 CDF 网格，或在持有完整原始历史时重算；没有必要为了第一轮诊断保存每个位置的整个大词表向量。

严格地说，P_t 是未加水印的基础采样分布；Gumbel-max 对理想随机向量边缘化后的 token 分布也为 P_t。固定实际密钥和完整历史时，当前水印采样输出本身是确定的。不能将这两个层次混为一谈。

如果观察 token W=w，还存在一个更细的条件模型：

\[
f_1(y\mid W=w,P)=\frac1{p_w}y^{1/p_w-1}.
\tag{11}
\]

在理想 null 的随机量与 token 独立条件下，f0(y|W,P)=1，因此可研究只用被选中 token 的基础概率 p_w 的条件得分

\[
\ell(y,w,P)=-\log p_w+(1/p_w-1)\log y.
\tag{12}
\]

它与边缘密度 sum y^(1/p-1) 不同。式 (12) 不是把实际人类 token 分布假定为 P 的完整联合最优似然比；若要做完整联合检验，还需相应的 null token 模型。对于缺失 prompt、编辑和重复上下文，任何上述条件得分都要重新核对假设及校准。式 (11) 的条件是 token 与 P，不是把完整 U 也固定。

### 4.2 只有待测最终文本：模型可访问不等于恢复原始 P

如果原始 prompt 不可见，或前文被编辑，重新运行同一个 LLM 得到的是 P_t^eval，不一定等于 P_t^gen。

当前 m=4 的协议允许：前 4 个 token 已恢复原样，当前 token 也保留，因此操作标签 Z=1；但更早历史仍有编辑，导致模型的完整上下文分布改变。因此水印 seed 已恢复不代表生成 P 已恢复。此时 f1,P_eval 是近似备择，不能称为精确真值。

统计框架论文第 2.2 节（PDF 第 8 页）明确指出：即使可访问 LLM，原始 prompt 的缺失仍可能使 P_t 不可获得。白盒 oracle 的实验价值在于测量这项差距，不能直接当成最终检测器具备的信息。

## 5. 不知道各条件概率，经验分布够不够？

### 5.1 对同一总体的边缘分布：可以直接估计

用 C 表示上下文或生成条件，定义目标水印位置的条件构成 Q1。边缘备择为

\[
\bar f_1(y)=\int f_{1,P(c)}(y)\,dQ_1(c).
\tag{13}
\]

如果纯水印校准样本确实来自该总体，且有足够的独立覆盖或适当遍历/弱依赖条件，经验 CDF 可以直接估计平均 CDF。每种条件出现的频率已经隐含在样本里，不需要分别估计高维条件的权重。

如果只用 Y 对同一总体中的随机位置作边际分类，边缘 f1 与相应先验是正确对象；条件性本身不会使这种做法失效。

### 5.2 校准与测试构成不同：无限校准样本也不解决

\[
\bar f_1^{cal}(y)=\int f_{1,P(c)}(y)dQ_1^{cal}(c),\qquad
\bar f_1^{test}(y)=\int f_{1,P(c)}(y)dQ_1^{test}(c).
\tag{14}
\]

若 Q1 不同，精确知道前者也不保证知道后者。尤其要估计的是测试中 Z=1 的位置所对应的条件构成，不只是原始文章的总体构成。即使编辑过程不读水印密钥，它也可能偏好修改某种文本，从而改变剩余水印位置的条件权重；如果编辑直接根据 Y 或水印得分选择，还可能改变每个条件内的分布，甚至破坏 null 模型。

一个明确的边界例子：校准 f1,strong=2y。测试中所有位置都启用了水印，但 a 比例的条件为 P=(1/2,1/2)，其余为 P=(1,0) 的无信息极限。于是

\[
f_{test}(y)=a\,2y+(1-a)\,1.
\tag{15}
\]

当前用 (1-e)+e*2y 拟合，会得到 e=a，而操作上启用水印的比例为 1。点质量条件不包含可辨识耦合，因此该例揭示了操作标签与统计可辨识性的边界；取 P=(0.999,0.001) 时不完全退化，仍会出现近似混淆。不能据此声称严格非奇异、固定分布下永远不可识别；它展示的是校准失配导致的偏差和弱信号下的困难。

对于仅用 X=-log Y 均值的比例估计，偏差更能直接写出。设真实比例 e、测试水印条件的平均 S2 为 s_test，校准对应值为 s_cal，则

\[
\mathbb E[X]=1-e+e s_{test},\qquad
e_{moment}^{cal}=\frac{1-\mathbb E[X]}{1-s_{cal}}
=e\frac{1-s_{test}}{1-s_{cal}}.
\tag{16}
\]

当前仓库用复合似然，而非这个均值估计器；式 (16) 用来清楚展示“比例”与“信号强弱”的混淆机制。

### 5.3 对 HMM：匹配一维边缘仍然不够

使用统一发射的 HMM 需要的不只是整体直方图正确，还要求状态给定后的序列分布能由该发射和转移结构合理近似。

若每个水印位置的条件独立地按相同 Q1 抽取，则把它们积分掉得到统一 f1 是合理的。若高/低信息条件在段落中持续存在，或者与 Z 的转移有关，真正需要的是依赖历史的条件发射。单个边缘 f1 不能恢复这种联合结构。HMM 可能把持续的低信息水印段当成 null 段。

SPOT v2 的 PDF 第 37 页对此有直接相关的条件混合形式：有效水印密度是对生成条件及存活概率按已观测历史加权得到的，并非固定的一条全局边缘曲线。

### 5.4 边缘化损失可用信息量表达

在水印总体 Q1 下，KL 混合分解给出

\[
\mathbb E_C D_{KL}(f_{1,P(C)}\Vert f_0)
-D_{KL}(\bar f_1\Vert f_0)
=\mathbb E_C D_{KL}(f_{1,P(C)}\Vert\bar f_1)
=I(C;Y\mid Z=1).
\tag{17}
\]

右边量化了观察 C 相比仅观察 Y 能增加多少区分信息。异质性不必然让边缘方法无效；它使边缘方法损失部分可用信息，而总体构成改变还会另外造成失配。

### 5.5 经验 CDF 与 HMM 密度比是两个估计目标

经验 CDF 的一致性不自动给出逐点密度或 log 密度比一致性。当前固定箱数直方图更自然地解释为对 Y 分箱后的似然比。若箱为 (a,b]，则

\[
g_{(a,b]}=\frac{F_1(b)-F_1(a)}{F_0(b)-F_0(a)}
=\frac{F_1(b)-F_1(a)}{b-a}.
\tag{18}
\]

对这种固定分箱决策，经验箱概率可以满足需要；它仍需代表性、足够覆盖和正确的序列建模。不能把有限网格经验分布等同于已知连续的全部条件似然。

## 6. 对项目最有辨别力的下一轮测量

这次先完成推导与理想数值验证，未更改生成器、HMM 或原实验协议。下一轮真实模型测量宜按以下顺序进行：

1. 在生成时未覆盖 logits 前取得真实 P_t，保存 pmax、H、S2、S3，以及预设 CDF 网格或对抽样位置计算的完整解析信息。指标按原始文章分组，不能把重复上下文都当独立样本。
2. 在纯水印的留出文章中，检验不同 S2/H 分组的 -log Y 均值是否符合式 (4)，以及 F1,P_t(Y_t) 是否近似均匀。这里的 PIT 是水印模型诊断，不是 null p 值。
3. 比较全局经验分布、按 S2 分组的经验分布、真实 P_t 的解析条件发射。前两者可验证统一 f1 的代价，第三者为 oracle 基准，不赋予最终检测器原始 prompt 或标签。
4. 对编辑后的保留 token，分别计算 P_gen 与 P_eval 的差异，比较原始、近邻编辑、远处历史编辑后的发射预测误差。特别区分 seed 失配与 P 失配。
5. 做“校准条件构成×测试条件构成”的交叉评价，观察比例偏差、IoU、后验可靠性及独立 null 文档误报。按信号强弱统计持续长度和残差相关，判断是否值得增加条件发射或额外的强弱状态。

若 oracle 条件发射相对边缘发射没有明显改善，优先保留简单方法；若 oracle 改善明显而可见最终文本重算 P 的版本改善有限，瓶颈是生成条件恢复；若按 S2 分组已接近 oracle，可考虑低维条件发射，而无需拟合每个上下文的独立分布。

## 7. 本次数值核对与可复现文件

独立脚本 [analyze_pivot_law.py](../scripts/analyze_pivot_law.py) 使用完整独立 U 向量做实际 Gumbel 竞争，以此检验式 (3)、条件 Beta 模型和 PIT；不是调用同一个理论枢轴采样器进行自我验证。它另以数值积分检验 KL 上界，并计算条件构成失配下的总体分箱最大似然。

默认每个场景 120000 个样本，7 个场景；200 对概率向量验证 CDF 稳定界和向均匀分布平滑后的随机序方向。数值结果是理论核对，不能当成固定密钥真实 LLM 或 CUDA 实验已通过。
