## 1. 一页摘要

## 2. 模型与记号

### 2.1 记号

| 记号 | 含义 | 范围 |
|---|---|---|
| `Y_t ∈ (0,1)` | 枢轴量（选中 token 对应的均匀随机数） | 每个位置 |
| `z_t ∈ {0,1}` | 隐状态，1 = 有水印 | 每个位置 |
| `f₀ ≡ 1` | 零假设下 `Y` 的密度 | — |
| `f₁` | 备择密度，估一次后**冻结** | 全局 |
| `ε_d` | 第 d 篇里水印位置的平均占比（**要报告的量**） | 逐篇 |
| `π` | 第一个位置的状态分布，`(1−π₁, π₁)`。PD：逐篇的 `π_d = (1−ε̂_d, ε̂_d)`；PE：全局自由参数；P1：逐篇的 `π_d`，由 `ε̂_d` 反解；P2：`π*` | 见各方案 |
| `A` | 转移矩阵 `[[a₀₀, 1−a₀₀], [1−a₁₁, a₁₁]]` | 全局，2 参数 |

后文常用两个派生量：

```
λ  = a₀₀ + a₁₁ − 1                       链的"粘性"，λ 越接近 1，状态越不容易换
π* = (1−a₀₀) / (2−a₀₀−a₁₁)               A 的平稳分布里"有水印"的概率
```

### 2.2 `π` 是初始分布，不要求平稳

标准 HMM 只要求 `π` 是第一个状态的分布，note 里写的也是"初始（第一个 token）分布"，没有要求平稳。

这里要特别讲清一件事，因为它决定了为什么有四个方案：

- **旧家族**（`ρI+(1−ρ)1πᵀ`）里，`π` 恰好同时是平稳分布，而且能逐篇不同。这是因为逐篇的 `ε` 被写进了 `A` 里。
- **新家族**里 `A` 是全局的，它的平稳分布 `π*` 由 `(a₀₀,a₁₁)` 唯一确定、所有文章相同。所以**不可能**再同时满足"`A` 全局""`π_d` 逐篇不同""`π_d` 是平稳分布"这三条。

四个方案各放弃一些：

- **PD（主之一）**：放弃"平稳"，保留"逐篇"。`π_d` 直接取 `(1−ε̂_d, ε̂_d)`，不要求它与全篇的平均占比对齐；
- **PE（主之一）**：放弃"平稳"和"逐篇"，`π` 是一个全局的自由参数，由数据决定第一个位置的状态；
- P1（附录）放弃"平稳"，换取逐篇的 `π_d`，并要求先验边际的篇内平均等于 `ε̂_d`；
- P2（附录）放弃"逐篇"，保留平稳。

PD、PE 并列作主方案的理由：两者都是 HMM 的标准用法，都没有 P1 的误差放大问题，差别只在首位状态的信息从哪里来。PD 从每篇自己的 `ε̂_d` 来，逐篇但依赖 `ε̂` 的质量；PE 从训练集学一个全局值，不依赖 `ε̂`，但对每篇都是折中。

### 2.3 四个方案

**PE（主之一）：`π` 与 `A` 联合 EM。** `A`、`π` 都全局，`π = (1−π₁, π₁)` 中的 `π₁` 是自由参数，从 `(0.5, 0.5)` 出发。EM 的 M 步有精确闭式：

```
π₁ ← (1/D) Σ_d γ_{d,1}(1)          D = mixed_cal 的篇数，γ_{d,1} 是第 d 篇第一个位置的后验
```

`π₁` 截到 `[0.01, 0.99]`，避免某个状态在首位的概率恰为 0，导致 test 上以该状态开头的文章似然为 0。

PE 的 `A` 与 `π` 一起优化，是**标准的 Baum–Welch**，没有近似，每步池化似然单调不降。训练好后全部冻结，test 时每篇文章共用同一个 `(A, π)`，推理里**用不到** `ε̂_d`。

需要说明的局限：`π₁` 反映的是 `mixed_cal` 里"首位更常是水印还是非水印"，由场景比例（`switch` 首位无水印，`resample` 首位多为水印）决定；test 的 `seg*` 首位全是水印。所以它是一个折中的全局值，不是每篇的真实起点。

**PD（主之一）：`π_d` 由 `ε̂_d` 直接给出。** `A` 全局（EM 估）；`π_d = (1−ε̂_d, ε̂_d)`，`ε̂_d` 是第 d 篇的 `ε̂_opt`（§5.1）。先估 `ε̂_d`，再直接定 `π_d`，不反解、不要求平稳。`ε̂_opt` 已投影到 `[1e-3, 1−1e-3]`，`π_d` 不会恰为 0 或 1，不用再截断。

2 状态链的先验边际有闭式：

```
P(z_t=1) = π* + (π_{d,1} − π*)·λ^{t−1}
```

代入 `π_{d,1} = ε̂_d`：`ε̂_d` 的影响按 `λ^{t−1}` 衰减，半衰期 `ln 2 / (−ln λ)` 个位置，之后先验趋于 `π*`。所以 PD 改的主要是开头一段的先验。这段有多长取决于 `λ̂`（§6.4 报）。作参考：L0 各场景的真值 `ρ`（旧家族里 `ρ` 就是 `λ`）在 0.83–0.984 之间（[l0_review §2](l0_review_20261103.md#L37-L47)，粗算），对应半衰期约 4–43 个位置。

另有一条间接作用：null 文章的 `ε̂_d` 接近 0，首位先验也接近 0。`null_cal` 上 `max γ` 的分布因此会变，`τ` 跟着变，所以 PD 也可能影响误报。

与相近方案的区别：

- **与 `opt_hmm`**：首位分布相同，都是 `(1−ε̂, ε̂)`。但 `opt_hmm` 把 `ε̂` 写进整个 `A`（`ρI+(1−ρ)1πᵀ`，`π` 同时是平稳分布），并逐篇网格选 `ρ`；PD 的 `A` 是全局 EM 学出的 2 参数矩阵，`ε̂` 只进首位。估计器也不同：旧方法用边际似然求根，PD 用 `ε̂_opt`。附录的 `opt_hmm_li` 换成了 `ε̂_opt`，它与 `pd_hist25` 主要差在 `A` 的学法（§6.1）。
- **与 P1**：用同一个 `ε̂_d`。P1 反解 `π_{d,1}`，使先验边际的篇内平均等于 `ε̂_d`，代价是把误差放大 `1/ᾱ` 倍；PD 不反解，`π_d` 的误差就是 `ε̂_d` 的误差。`λ→1` 时 `ᾱ→1`，两者重合。
- **与 P2**：`A` 同族，只差首位先验（PD 取 `ε̂_d`，P2 取 `π*`）。`λ̂` 小时，PD 在开头几个位置之后与 P2 无异。

EM 时 `π_d` 固定、不是参数，M 步只更新 `(a₀₀,a₁₁)`，仍是精确 EM（§5.2）。推理时每篇先用冻结的 `f₁`、`cap` 算 `ε̂_d`，再做前向–后向。所以 PD 不像 PE 那样完全冻结：`f₁` 失配造成的 `ε̂` 偏差会直接带进首位先验（§8）。

**P1（附录）：逐篇按平均占比对齐。** `A` 全局；`π_d` 由 `ε̂_d` 反解，使"先验边际"在篇内的平均恰好等于 `ε̂_d`。

用上面的先验边际闭式，对 `n=128` 个位置取平均：

```
ᾱ = mean_t λ^{t−1} = (1−λⁿ) / (n(1−λ))
π_{d,1} = clip( π* + (ε̂_d − π*) / ᾱ , 0, 1 )
```

`ᾱ` 只依赖全局 `A`，算一次缓存。

**必须知道的性质：这个反解会把 `ε̂` 的误差放大 `1/ᾱ` 倍。** 例如 `a₀₀=a₁₁=0.95`，`λ=0.9`，`ᾱ≈0.078`，放大约 13 倍：`ε̂_d` 偏 0.05，`π_{d,1}` 就偏 0.65，多数文章会被 clip 到 0 或 1。直觉是：链粘性不高时，开头那个状态几十步后就忘了，靠改 `π_d` 几乎调不动全篇平均占比。因此 P1 只有在 `λ` 很接近 1（链很粘）时才有意义，否则它基本等价于"把首位状态硬设成 0 或 1"。这不是实现问题，是 P1 设计本身的性质，所以每次都要报 `ᾱ` 与 clip 比例（§6.4）。

契约检查：反解后，**先验边际**的篇内平均应等于 `ε̂_d`（注意是先验，不是后验 `γ`）。被 clip 导致偏差 > 0.02 的文章标记 `pi_clipped`。

退化保护：`ᾱ < 0.05`（放大超过 20 倍）时，`π_d` 不可靠，退回 P2 的平稳 `π`，标记 `pi_unidentifiable`。

**P2（附录）：全局平稳。** `A`、`π` 都全局，`π = (1−π*, π*)`，`π` 由 `A` 决定、不单独学。训练语料上估一次、冻结，test 时所有文章共用。模型里没有逐篇信息，`ε̂_d` 只用来报告。**P2 就是把 `fixed_e` 里拍脑袋的 0.5 换成学出来的 `π*`。** PE 与 P2 的差别只在 `π` 是否被允许偏离平稳分布。

### 2.4 `f₀ ≡ 1` 什么时候成立

文献写的是 `U_{t,w_t} ~ Unif(0,1)` under H₀（`papers/text/2025_aos_statistical_framework.txt:721-724`），但这挂在 Working Hypotheses 2.1 / 2.2 上（同文件 `:330-358`）：伪随机数 iid 且与历史独立、token 与随机数独立。文本被编辑后 `P` 会变、重算 `P` 有误差、重复上下文使 `ζ` 不严格 iid，这三种情况都会让真实的 `f₀ ≠ 1`。

本轮**不改** `f₀`（它是枢轴的定义），只加诊断：在 `null_cal` 上估 `f̂₀`，报 `sup|f̂₀−1|` 与逐箱偏差（§6.4）。

3. 只有 PD、PE 两个方法都满足 `τ < 1` 且可检出位置数 > 0 的族才有资格；得分最高者为 `param*`；并列时取候选表中靠前者（`beta, beta_mixture, truncnorm, logitnorm, gamma, weibull, lognormal`）；
4. 若 7 个族都没有资格，取 `beta` 并在报告里标注；
5. **不读 `dev2`、`test`、`test_seg`、`null_test` 来选族。** 入选结果写进 `frozen.json`，S4 不重选（S3 与 S4 的输入相同，规则确定，结果应一致；不一致只可能是 S3 之后改了代码，须在报告里说明）。

### 3.2 `ecdf400` 怎么建（附录）

1. **ECDF**：用 `calibration ∪ calibration2` 的**全部**枢轴（100 篇 × 124 ≈ 12,400 个点）。
2. **节点**：共 401 个。两端固定为 `(0,0)` 和 `(1,1)`；中间 399 个取第 `⌈k·n/400⌉` 个次序统计量（`k=1..399`），纵坐标 `k/400`。这样每段的概率质量恒为 `1/400`，尾部点密→段窄→密度高，正好保住尖峰。
3. **保单调插值**：对这些节点用 Fritsch–Carlson 保单调三次 Hermite（PCHIP）。CDF 连续、单调，导数即密度，恒正。
4. **求导**：PCHIP 的导数是分段二次，解析写出，不数值差分。
5. **检查**：`∫f̂₁ = 1`（`integral_mass` 已有）；`cap` 会削掉质量，报 `mass_under_cap`。

端点必须固定在 `(1,1)`：否则最大样本之后 CDF 是平的，密度为 0，而 `hmm._emissions` 要求密度比严格为正。

只用 numpy，不引入 scipy。

### 3.3 `cap` 与截断方式

**为什么不能省**（这条论断由 §3.5 的 nocap 旁支检验）：ECDF 在最大样本附近的密度量级是 `~1/(n·gap)`，不截断的话，在样本稀少的位置上哪怕 `y≈0.999` 也能得到 `g≫1`，HMM 后验饱和，any-FP 爆表。

**候选网格**：`K ∈ {5, 10, 25, 50, 100, 250, 1000}`。ECDF 的原始上界可到 `10³`，所以网格上端取到 1000。

直方图的密度有天然上界：`bins·(c+0.5)/(N+0.5·bins) < bins`（`emissions.py:52`），上界以上的 `K` 与不截断完全相同，在 dev 上必然打平。所以只取有效值：

| 发射族 | 候选 | 说明 |
|---|---|---|
| hist25 | `{5, 10, 不截断}` | `K ≥ 25` 都等于不截断；L0 的 `cap=25` 实际上就是不截断 |
| hist200 | `{5, 10, 25, 50, 100, 不截断}` | `K ≥ 250` 都等于不截断 |
| ecdf400 | 全网格 | 没有天然上界 |
| 7 个参数族 | 全网格，不含"不截断" | 参数密度可能无界（如 `beta` 的 `b<1`、`beta_mixture` 的分量），密度比必须有限，故不设"不截断"；不用 `s` 尺度幂律截断 |

IoU 相同时取截断较少者（较大的 `K`）。

**两种截断方式，在 dev 上二选一：**

- **硬 cap（默认）**：`f̃ = min(f, K)`。简单，但在 `y` 轴上留下一道人为的棱。
- **`s` 尺度幂律截断（条件启用）**：令 `s = −log(1−y)`，`y` 越接近 1，`s` 越大。尾部真实形状接近幂律，所以在 `s > s₀`（即 `y > y₀ = 1−e^{−s₀}`）处，把 `y` 上的密度改为幂律外推：

  ```
  f̃(y) = min( f(y₀)·((1−y)/(1−y₀))^{−β} , K ),   y > y₀
  ```

  在 `s` 尺度上这是一条直线：`log f = β·s + c`。参数与拟合方式：
  - `y₀ ∈ {0.90, 0.95, 0.99}`，在 dev 上选；
  - `β`：在 `calibration ∪ calibration2` 的 ECDF 密度上，对 `s>s₀` 的点回归 `log f` 对 `s`，取斜率并截到 `[0, 0.95]`（`β<1` 才可积）；`β` 不随 dev 调；
  - `K` 沿用上面的网格。

  **只有当 ecdf400（附录）的硬 cap 最优 `K` 顶到网格上界（1000）时才启用**——那说明截断位置本身在主导结果。直方图选到"不截断"不触发：它们本来就有上界，顶到上界不说明问题。参数族的最优 `K` 顶到 1000 时只标注，不启用幂律截断（参数族自带尾部形状）。

**选法**：在 `dev`（旧四场景里的 `switch`、`resample_0.1`、`resample_0.3` 三个定位场景，共 30 篇）上，用 §5 第 4 步已估好的 `A`、`π`，每个方法各选一个 `K`：取三场景平均 IoU 最大，且 `τ < 1`、可检出位置数 > 0 的 `K`。参数族的入选（§3.1）紧接在这一步之后，用的是这里得到的各方法 `dev` IoU。**不用 null 选 `cap`**，`null_cal` 要留给 `τ` 校准，共用会让误报被低估。

### 3.4 `f₁` 为什么不进 EM（`A`、`π` 进）

1. **label switching**：`A`、`π`、`f₁` 三者一起学，两个状态可以对调；只有冻结 `f₁` 才能锚定。`f₁` 冻结后，状态 1 就被钉在"枢轴偏大"的一端，`A`、`π` 的 EM 不会翻转。
2. **来源不同**：`f₁` 来自纯水印校准文本，混合文本里的备择分布本来就不同源。在混合文本上用 EM 更新 `f₁`，会把"分布失配"（[实际实验 §4.3](实际实验.md#L187-L193)）和"参数学习"混成一团。
3. **一次只改一件事**：本轮要判读的是 `A` 和发射族，`f₁` 再进 EM 就没法归因了。

所以 `f₁` 的流程固定为：calibration 上估一次 → 冻结 → 一路用到 test。参数族也一样：参数只估一次，不随 EM 更新。

### 3.5 诊断旁支：去掉全部 `cap`（nocap）

**目的**：检验 §3.3 里"`cap` 不能省"这个论断到底成不成立，并量化 `cap` 压掉了多少信息。它是**诊断性旁支，不进主表、不参与任何选择**（不用来选 `cap`、不用来选方法）。

**做法**：hist200、`param*`、ecdf400 三族取 `cap = ∞`（配置里 `cap: null`），其余全部照主线，强行算下去。`param*` 的名字在 S3 选出之后才知道，所以 `param*` 的 nocap 在 S3 之后跑，另两个可与 S3 并行。hist25 不单列：它的密度 `< 25`，不截断与 `cap=25` 完全相同（§3.3）。

1. `f₁`：同主线的 hist200 / `param*` / ecdf400，不截断；
2. `A`、`π`：只跑 PE（PD 与 PE 用同一个 `g`，`cap` 的作用看 PE 一侧即可），在 `mixed_cal` 上用不截断的 `g` 重新做 EM（不能借用主线的 `Â`，因为发射变了）；
3. `τ`：在 `null_cal` 上重新校准；
4. 评价：只在 `dev` 和 `dev2` 上跑，**不读 `test`、`test_seg`、`null_test`**。

没有"选 `cap`"和"重估"两步。方法名：`pe_hist200_nocap`、`pe_<param*>_nocap`（如 `pe_beta_nocap`）、`pe_ecdf400_nocap`。若主线的 hist200 在 dev 上选到"不截断"，`pe_hist200_nocap` 就与主线的 `pe_hist200` 相同，照记。

**要记录的现象**（"强行"的意思是：即使退化也照算、照报，不当作失败丢掉）：

- **密度上界**：各族不截断时的 `max f₁`、`y∈[0.99,1]` 与 `y∈[0.999,1]` 的密度；纯水印校准文本与 `null_cal` 里落在这两个区间的位置数，以及被主线 `cap` 截掉的位置比例。
- **后验饱和**：在 `null_cal` 上 `γ_t>0.999` 的位置占比；`max γ` 是否在浮点精度内等于 1。
- **`τ` 退化**：`τ` 的取值；`τ=1`（或可检出位置数为 0）时，该方法在 `dev2` 上等于什么都检不出，照实记。
- **`A` 的变化**：与主线 `Â`（同族、PE）对照，看 `cap` 是否改变转移参数；`ℓ_EM` 是否异常，是否贴边。
- **效果**：`dev`、`dev2` 上与主线同族 PE 的 ΔIoU、边界误差；`dev2` 上的 any-FP 只能在 `null_cal` 上算，同样是乐观值，仅作参考。
- **数值健康**：`g` 的最大值是否让前向递推下溢或溢出；`ε̂_opt` 的 `v` 在大 `g` 处是否稳定（`v` 有上界 `1/ε`，预期稳定）。

**怎么读**：

- 若 nocap 明显退化（`τ` 顶到 1、饱和严重、IoU 掉），说明 `cap` 确实在起保护作用，§3.3 的论断成立；
- 若 nocap 与主线差别很小，则说明 `cap` 在当前数据上不起决定作用，主线结论对 `cap` 不敏感，`cap` 网格上界、`s` 尺度幂律截断都可以不启用；
- 若 nocap 反而更好，则当作"`cap` 把真实尖峰压平了"的证据（§1 的 Q3），但**不据此在本轮改主线**：改主线须另起版本，且不能用 `dev2` 同时选择与比较。

## 4. 数据、场景与角色

### 4.1 为什么必须新增混合 calibration

`A` 的信息量来自**状态切换次数**。L0 的 calibration 全是纯水印文本，代码还强制断言其 truth 全为 1（`l0/evaluate.py:195`），所以 `ε=1`、状态恒为 1、**切换次数为 0**，`(a₀₀,a₁₁)` 完全不可识别。

因此新增 `mixed_cal`，提供真实的 0→1 与 1→0。不能用 dev（留给 `cap`），不能用 test（会泄漏）。

### 4.2 角色：只追加，不改已有角色

目标：已有五个角色的文章集合与 `l0full0` **逐位相同**，旧数字继续可比。

**光追加不够。** `data.py:67` 对**全部**候选文章做 `rng.shuffle`，而 `numpy` 的洗牌结果依赖列表总长度：总篇数一变，已有角色拿到的文章整体换掉。

**修法**：候选的收集顺序（由 `rng.permutation` 决定）与总篇数无关，所以前 `N_old` 篇候选仍与 L0 相同。只对这前 `N_old` 篇做 `rng.shuffle`（与 L0 一致），新角色按收集顺序从 `N_old` 之后依次取，不再洗牌。

| 角色 | 篇数 | 场景（每篇一种，按序轮转） | 状态 | 用途 |
|---|---:|---|---|---|
| `calibration` | 50 | 纯水印 | 不变 | 基线 `f₁` |
| `dev` | 40 | 旧 4 场景 | 不变 | `cap` 选择；`param*` 入选；`seedbs` 的 `(B, ζ)` |
| `test` | 160 | 旧 4 场景 | 不变 | 最终 test（只跑一次） |
| `null_cal` | 400 | 无水印 | 不变 | `τ` 校准（含 `seedbs` 的 `c`） |
| `null_test` | 400 | 无水印 | 不变 | any-FP |
| `calibration2` | 50 | 纯水印 | **追加** | 与 `calibration` 合成 100 篇估 `f₁` |
| `mixed_cal` | 50 | `switch`、`resample_0.1`、`resample_0.3` 轮转（约 17/17/16） | **追加** | 估 `A` 与 `π` |
| `dev2` | 60 | `seg2/3/4` 各 20 | **追加** | S1–S3 的**唯一**比较集 |
| `test_seg` | 120 | `seg2/3/4` 各 40 | **追加** | 最终 test 的分段部分 |

L0 的 `plan_jobs` 是**一篇一次生成**，所以总生成量是 1,330 次（旧 1,050 + 新 280），新增只有 280 次。

**一致性检查**：用含新角色的配置重新 `prepare`，旧五个角色的 `sources.jsonl`（文章 id、顺序、prompt）必须与 `l0full0` 逐篇相同。

### 4.3 分段场景：照 1.pdf 的设置

1.pdf（`Segmenting Watermarked Texts From Language Models`）用长度 `m=500` 的文本，四种设置（`papers/text/segment_existing.txt:531-580`）：

| 论文设置 | 构造 | 切换点（m=500） | 水印段数 |
|---|---|---|---:|
| Setting 1 | 500 全部水印 | 无 | 1 |
| Setting 2 | 250 水印 + 250 无水印 | 251 | 1 |
| Setting 3 | 500 水印，替换 201–300 为无水印 | 201, 301 | 2 |
| Setting 4 | 400 水印，替换 101–200，并在 300 处插入 100 无水印 | 101, 201, 301, 401 | 3 |

Setting 1 就是我们的 `full_wm`，不重复。其余三个**按比例**映射到 128 个位置（论文每段 100/500 = 20%，128 下约 25.6 个位置）：

| 场景 | 对应 | 切换点（128） | 水印段数 | `ranges`（比例） |
|---|---|---|---:|---|
| `seg2` | Setting 2 | 64 | 1 | `[[0,.5]]` |
| `seg3` | Setting 3 | 51, 77 | 2 | `[[0,.4],[.6,1]]` |
| `seg4` | Setting 4 | 26, 51, 77, 102 | 3 | `[[0,.2],[.4,.6],[.8,1]]` |

现有 `switch`（`[[.2,.7]]`，1 段 2 个切换点）保留，作"单岛"基线。

**实现方式**：不复刻论文里"插入 / 替换"的编辑动作，而是在生成时用**区间开关**（`ranges` 的空白处即不加水印）。所以这是**结构同构、不是逐字复刻**：段数、切换点位置、段长按比例对齐，但文本长度是 128 而非 500。报告里必须写明这一点。

**可选压力测试**：论文附录 B.5 把切换点加到 4、8、12 个（`segment_existing.txt:1893-1902`），12 个时论文自己的方法也只找回 9 个。128 个位置下 12 个切换点意味着每段约 10 个位置，已逼近 HMM 的分辨极限。作为可选场景，默认不进主表，需要时另起版本。

**代码改动面**：L0 路径的 `plan_jobs`（`l0/generate.py:26-30`）目前只有 `switch` 一个多区间入口，改成按场景名从配置里取 `ranges` 即可，核心生成逻辑不用动。

### 4.4 `dev2` 是 S1–S3 的唯一比较集

S1–S3 阶段之间的比较**只在 `dev2` 上做**；`test` 和 `test_seg` 到 S4 之前全程不可读。原因：若每个阶段都拿 test 比较，等于对 test 做了四次选择，最终"一次性 test"就失去意义。

代价：`dev2` 每类只有 20 篇，边界误差的分辨力有限。所以阶段结论只报方向与区间，不要求显著。

`dev2` 上的 any-FP 只能在 `null_cal` 上算（没有独立 null），是**乐观值，只用于阶段内排序**；正式 any-FP 在 S4 的 `null_test` 上。

### 4.5 旧结果处置

`l0full0` 的五个角色与文章集合不变（以 §4.2 的一致性检查为准），旧数字继续有效，作为本轮基线。新增角色不进入旧报告。

## 5. 估计与冻结顺序

严格按序，前一步冻结后才做后一步；`test` / `test_seg` / `null_test` 到 S4 之前不可读。**先估 `A`，后选 `cap`**。但估 `A` 需要有限的发射密度，所以先用一个临时 `cap`，选完再重估一次，不再迭代。

1. **`f₁`**：`calibration ∪ calibration2`（100 篇）的全部枢轴 → hist25、hist200、ecdf400 与 7 个参数族，共 10 份。
2. **临时 `cap`**：所有发射族统一取 `K₀ = 25`（L0 的取值），只为让 `g` 有限。
3. **`ε̂_d`**：逐篇用 Li et al. 的 `ε̂_opt`（§5.1），用 `f₁` + `K₀`。PD（主）与 P1（附录）用得到，PE、P2 不需要；所有方法都拿它报 `ε` 误差。
4. **`A`、`π`**：在 `mixed_cal` 的 50 篇上跑 **EM**（做法见 §5.2）。`π` 的处理不同，所以每个"方案 × 发射族"各估一份，共 24 份：`pd`、`pe` 各配 hist25、hist200、ecdf400 与 7 个参数族（20 份），再加 `p1_hist25`、`p1_ecdf400`、`p2_hist25`、`p2_ecdf400`（4 份）。主表是其中的 `pd_hist200`、`pe_hist200`、`pd_<param*>`、`pe_<param*>`，其余进附录。网格作附录对照。
5. **`cap` 与 `param*`**：在 `dev` 上按 §3.3 选，每个方法各一个 `K`（用第 4 步的 `A`、`π`）；随后按 §3.1 的规则从 7 个参数族里选出 `param*`。`seedbs` 的 `(B, ζ)` 按同一规则选（§5.3）；它不依赖第 1–4 步，实际在 S1 就选定（§7）。
6. **重估**：用选定的 `cap` 重做第 3、4 步各一次，得到最终 `Â`；报新旧 `Â` 之差。若某方法选出的 `K` 就是 25（hist25 的"不截断"也是），这一步结果不变。
7. **`τ`**：在 `null_cal` 上按方法 × 长度校准（按 `n_eff` 分组，小组退回池化；`max γ` 的 `1−α` 分位，`rank = ceil(401×0.95) = 381`），沿用现有实现。`seedbs` 的 `c` 用同一实现（§5.3）。
8. **一次 test**：主表四格、`seedbs` 与全部附录方法（含 7 个参数族全部的 `pd`、`pe`）在 `test + test_seg` 上跑一次，`null_test` 上跑 any-FP。

`frozen.json` 记录：10 份 `f₁`（含 7 个参数族的参数）、`param*` 的名字与入选表（各族 `dev` 得分）、24 份 `(a₀₀,a₁₁)` 以及 PE 的 `π₁`、`cap` 及截断方式、`τ`、`π` 策略与版本号；`seedbs` 的 `B`、`ζ`、`B′`、`a`、最短区间、`T`、`T′`、`c` 与随机种子。

### 5.1 `ε̂_d` 的估计器

**用谁**：Li et al. 2025（`papers/text/2506.22343v1_proportions.txt`，式 (7)–(9)）的 `ε̂_opt`。opt 论文（`2608.14906`，SPOT）也用它估存活水印比例。它有 minimax 最优性的证明，不用 EM。

**定义**：记 `ĝ` 为带 `cap` 的 `f₁`（与 HMM 用的是同一个密度比），权函数

```
v(ε, x) = (1 − ĝ(x)) / ((1−ε) + ε·ĝ(x))
T(ε)    = [ ∫v dF₀ − mean_t v(ε, Y_t) ] / [ ∫v dF₀ − mean_wm v(ε, Y^wm) ]
ε̂_opt  = T 的不动点，再投影到 [1e-3, 1−1e-3]
```

- `∫v dF₀` 是 `v` 在 `[0,1]` 上的积分，数值求积；`mean_wm` 是对 `calibration ∪ calibration2` 全部纯水印枢轴取平均。这两项只依赖 `(f₁, cap, ε)`，每个发射族算一次缓存；
- 每篇只需算 `mean_t v(ε, Y_t)`，`t` 取这篇的全部 `n_eff` 个位置（L0 不剔除位置，见 §5.2）；
- `ĝ ≈ 1` 处处成立时不可识别，沿用现有处理（`identifiable=False`）。

**求解**：不迭代 `ε ← T(ε)`（论文没给收敛保证），改为在 `[1e-3, 1−1e-3]` 上对 `T(ε) − ε` 二分求根；无变号就取残差绝对值较小的端点，并标记 `eps_boundary`。

**与现有估计器的区别**：现有的 `estimate_proportion` 令边际似然的得分为 0，允许精确的 0 或 1；`ε̂_opt` 取的是论文的矩恒等式，端点收在 `1e-3` 内。两者都依赖校准得到的 `f₁`，所以对 `f₁` 失配同样敏感，只是换成有理论保证的版本。

**用在哪里**：PD 的 `π_d`（EM 训练与推理都用）、P1 的 `π_d` 反解及它在 EM 中固定的 `ε̂_d`、`ε` 误差的报告。PE 与 P2 的推理不依赖它。四个旧方法按其原样仍用旧估计器；附录的 `opt_hmm_li` 是 `opt_hmm` 换用 `ε̂_opt` 的版本（§6.1）。

**诊断**：在 `mixed_cal`、`dev2` 上同时算旧估计器，报两者之差与各自对真值的误差（§6.4）。

### 5.2 `A`、`π` 的 EM 怎么做

**设定**：`mixed_cal` 的 50 篇池化，`f₁` 冻结，只学 `(a₀₀,a₁₁)` 与 `π`。每篇用全部 `n_eff` 个位置：L0 不剔除任何位置，编辑造成的破坏窗口内 truth 记 0，但枢轴照常输入（`l0/schema.py:36-45`）。`mask` 只是接口参数，在 L0 数据上恒为真。

**E 步**：每篇做前向-后向，得到 `γ_t`，以及相邻位置对的后验 `ξ_t(i,j) = P(z_t=i, z_{t+1}=j | Y)`（现有 `hmm.py` 没有，S0 要加）。只统计相邻两位置都在 `mask` 内的对。

**M 步**：

```
a₀₀ ← Σ_{d,t} ξ_t(0,0) / Σ_{d,t} [ξ_t(0,0)+ξ_t(0,1)]
a₁₁ ← Σ_{d,t} ξ_t(1,1) / Σ_{d,t} [ξ_t(1,0)+ξ_t(1,1)]
π₁  ← PE：(1/D) Σ_d γ_{d,1}(1)，截到 [0.01, 0.99]（精确闭式）
      PD：不更新，π_d = (1−ε̂_d, ε̂_d) 固定（ε̂_d 只依赖 f₁ 与 cap）
      P2：π = 平稳分布(新 A)
      P1：每篇 π_d 由新 A 与固定的 ε̂_d 闭式反解（§2.3）
```

**PE、PD 都是精确的 EM**：PE 的 `a₀₀, a₁₁, π₁` 各自的 M 步都是闭式，互不牵连，池化对数似然每步不降。PD 的 `π_d` 是固定的已知量、不是参数，M 步只有 `a₀₀, a₁₁` 两个闭式，同样每步不降。`a` 截到 `[0.50, 0.999]` 是对各自一维凹函数的投影，仍是约束下的精确最大化，不破坏单调性。PE、PD 的测试都要求每步严格单调。

**P1、P2 要如实说明的近似**：`π` 在这两个方案里都是 `A` 的函数，不是独立参数，所以第三行不是标准 M 步（精确做法要对 `(a₀₀,a₁₁)` 联合数值优化）。我们只在转移项上做精确更新，首位项（每篇 1 项，对 127 项转移）被忽略。后果是不保证每步严格单调，所以：

- 每步用前向算**精确**的池化对数似然（不是 EM 的下界）来监控；
- 若某步下降超过 `1e-8`，停在此前最佳的一步，并标记 `em_nonmonotone`；
- 测试里另做"PE、PD 的 EM 严格单调"检查，保证 E/M 步本身没写错。

**其余约定**：

- **范围**：`a₀₀, a₁₁` 每步截到 `[0.50, 0.999]`，与网格的范围一致，便于对照。
- **起点**：`(a₀₀,a₁₁) ∈ {(0.9,0.9), (0.99,0.8), (0.8,0.99), (0.6,0.6)}`，PE 的 `π₁` 起点取 0.5，再加附录网格的最优点；取池化对数似然最大者。各起点终点相差 > 0.01 就标"多峰"。
- **收敛**：相邻两次池化对数似然增量 < `1e-6`，或到 500 步。
- **区间**：按篇 bootstrap，重抽 50 篇重跑 EM（以最优起点热启动），500 次。参数族候选在 `param*` 选出之前不做 bootstrap（14 个方法 × 500 次太贵，且选族用不到）；选出后，只对 `param*` 的两个方法做，其余 6 个族不报区间。
- **`a₀₀=a₁₁` 检验**：约束 EM（`a₀₀=a₁₁=a`，`a = Σ(ξ₀₀+ξ₁₁)/Σξ`），似然比 `2(ℓ_自由 − ℓ_约束)` 按 `χ²₁` 近似；同时看 bootstrap 里 `a₀₀−a₁₁` 的区间是否含 0。两者只作参考，不单独定论。

**附录：网格对照**：`a₀₀, a₁₁ ∈ {0.50, 0.51, …, 0.99, 0.995, 0.999}`，共 52 × 52 = 2,704 点，每点算同一个池化前向对数似然（PE 在每个格点上还要优化 `π₁`：第 d 篇的似然是 `π₁` 的线性函数 `(1−π₁)B₀ + π₁B₁`，池化对数似然对 `π₁` 是凹的，一维二分即可精确求出，所以网格给的是 `π₁` 的剖面似然）。它是 EM 的校验：连续优化的结果不应低于离散网格的最优，即 `ℓ_EM ≥ ℓ_网格 − 1e-6`。若不满足，说明 EM 落入局部最优，以网格最优点为起点再跑一次；仍不满足就冻结网格值并标注。网格还给出似然面剖面图。

### 5.3 `seedbs`：1.pdf 的并列基线

**来源**：Li, Li & Zhang，*Segmenting Watermarked Texts From Language Models*（NeurIPS 2024；`docs/1.pdf`，全文 `papers/text/segment_existing.txt`）。用它的 Algorithm 1（SeedBS-NOT，`:446-475`），检测量取 EMS（式 (2)，`:196`）：我们的水印就是它的 Example 2（指数最小采样，与 Gumbel-max 等价，`:163-168`）。

**流程**（`m = n_eff`，整篇一条序列）：

1. **分数**：`h_t = log Y_t + 1`。`Y_t` 与 HMM 用的是同一个枢轴；H0 下 `−log Y_t ~ Exp(1)`，`h_t` 均值 0、方差 1。不用 `f₁`。
2. **窗口 p 值**（式 (8)，`:305-319`）：窗口 `I_i = [(i−B/2)∨1, (i+B/2)∧m]`，统计量 `M_i` 是窗口内 `h_t` 的平均；`p_i = (1 + #{r : M_i ≤ M_i^{(r)}}) / (T+1)`，`T = 999`。
3. **切换点**：
   - KS 扫描：式 (9)（`:324-335`），在每个 SeedBS 区间上取切换点 `ĵ = argmax_j S(j)`（论文记作 `τ̂`；本文 `τ` 已用作阈值，改记 `j`）；
   - 显著性：式 (10) 的移动块自助（`:336-375`），块长 `B′ = B`，`T′ = 1999`；在每个区间内部单独做，区间长 `l` 不是 `B′` 的整数倍时抽 `⌈l/B′⌉` 块，拼接后截成长 `l`；
   - SeedBS 区间：照 Algorithm 1 的 `n_k`、`l_k = m·a^{k−1}`、`s_k` 逐层生成，`a = 1/√2`，只保留 `l_k ≥ 2.5B` 的层；
   - NOT：`O = {区间 : p̃ < ζ}`（严格小于，照 Algorithm 1）；反复取 `O` 中最窄的区间，记下它的 `ĵ`，删去所有含该 `ĵ` 的区间，直到 `O` 为空。

**必须改的三处**（论文针对"固定钥匙序列 + 编辑攻击"，我们的水印是上下文哈希）：

1. **不做钥匙对齐。** 论文的 `ϕ = max_k M(ξ_{J_k}, ỹ_{I_i})` 是在钥匙序列上搜索对齐位置（`:319`）。上下文哈希下每个位置的随机数由前 4 个 token 决定，位置天然对齐，所以窗口只与同位置的随机数配对（`J = I_i`），不在钥匙序列上取 max。
2. **"换钥匙"用 iid `U(0,1)` 代替。** 随机化的每次复制在全篇共用一组 `U(0,1)`，与论文"同一把新钥匙算所有窗口"一致。它与真换钥匙只在同篇内重复出现同一（上下文, token）对时不同（L0 不剔除这类重复，见 §5.2；重复对 `f₀` 的影响见 §2.4）。窗口 p 值保留随机化形式，不换成精确分布，以免改动基线本身。
3. **补一步段标签。** 论文只输出切换点（用 Rand index 评价），不判断哪段是水印。我们的主终点 IoU 需要逐位置标签，所以补一个段检验：
   - 切换点把全篇分成若干段。长 `L` 的段，H0 下 `−Σ log Y_t ~ Gamma(L, 1)`，段 p 值取下尾概率 `P(Gamma(L,1) ≤ −Σ log Y_t)`（整数 `L` 时等于 `P(Poisson(s) ≥ L)`，`s = −Σ log Y_t`，只用 numpy）；
   - 每个位置的分数取 `1 − p(所在段)`。这样 `τ` 的校准、标签（分数 `> τ`）、any-FP 全部复用现有 `decide`，等价于"段 p 值 `< c` 就标为水印"，`c = 1 − τ`；
   - 校准在 `null_cal` 上做，分组与秩同 HMM 方法（池化时 rank 381/400，即 `c` 取 400 篇"最小段 p 值"中第 20 小的值，严格小于），误报口径因此与四格一致。只用规则 M；规则 P（`fraction_tau`）对这种分数没有意义，不报。

段是从同一份数据里挑出来的，段 p 值本身不是有效 p 值；误报控制来自 `null_cal` 的校准，不依赖它。

**论文没写死、由我们定的参数**：

| 参数 | 取值 | 理由 |
|---|---|---|
| `a` | `1/√2` | 论文印作 `√2`（`:522-524`），与它自己要求的 `a ∈ [1/2, 1)`（`:448`）矛盾 |
| 最短区间 | `2.5B` | 论文 `B=20` 时为 50（`:525`），按 `B` 等比缩放 |
| `T′` | 1999 | 论文没给。`p̃ ≥ 1/(T′+1)`，`T′=999` 时 `p̃ < 0.001` 永远不成立，`ζ=0.001` 那一档就形同虚设 |
| `B′` | `= B` | 照论文主设置（`:521`） |

**调参**（与 `cap` 同一规则）：`B ∈ {6, 10, 14, 20}`、`ζ ∈ {0.05, 0.01, 0.005, 0.001}`，共 16 组。

- `B`：论文要求偶数（`:306-307`）。20 是论文主设置；14 是论文经验式 `⌊3n^{1/3}⌋`（`:2011`）在 `n=124` 处的值；10 是论文附录 C 网格的最小值（`:1989-1994`）；6 照顾我们更短的段（`seg4` 每段约 25 个位置）。
- `ζ`：论文的四档（`:526`）。
- 选法：对每组先在 `null_cal` 上校准 `c`，再在 `dev` 的三个定位场景上算平均 IoU，取最大者；同样要求 `τ < 1`（即 `c > 0`）、可检出位置数 > 0，IoU 相同时取较大的 `B` 与较小的 `ζ`。窗口 p 值与 `p̃` 只依赖 `B`，`ζ` 只改 `O`，所以每个 `B` 只算一遍。

**数据不对称**：`seedbs` 只用 `dev`（调参）与 `null_cal`（`c`）。四格另用了 150 篇训练文本（100 篇估 `f₁`，50 篇 `mixed_cal` 估 `A`、`π`）。报告里必须写明。

**不做的**：EMSL / ITSL（Levenshtein 对齐，针对插入、删除，我们的场景没有）、ITS（另一种水印）。论文的数字（`m=500`；GPT-2 / OPT-1.3B / Llama-3-8B；编辑攻击）不能与我们的直接比较，只比我们自己重跑的结果。报告里称"按 1.pdf 适配"，不称"复现"。

**随机性**：随机化与自助的种子按篇固定（由全局种子与文章 id 派生），写进 `frozen.json`。

### 6.2 终点

- **主终点**：6 个定位场景（`switch`、`seg2`、`seg3`、`seg4`、`resample_0.1`、`resample_0.3`）的**平均 IoU**。
- **次终点**：
  1. any-FP（`null_test`，重校准分布口径）；
  2. 边界误差（预测边界与真值边界的绝对位置差，仅 `seg*`）；
  3. Rand index：定义同 1.pdf，比较"检出切换点划出的段"与"真值切换点划出的段"（`segment_existing.txt:582-584`）。HMM 方法的段取标签的连续段；`seedbs` 取它自己的切换点，与论文一致。数字只与我们重跑的 `seedbs` 对照，不与论文的图表比（长度、模型、攻击都不同，§5.3）；
  4. `ε` 误差（所有方法统一报 `ε̂_opt` 对真值的 `|ε̂−真值|`；PD 的首位概率就是它；另报 PE 的 `π̂₁`、P2 的 `π*`）；
  5. 后验 `mean γ` 与 `ε̂_d` 的差（所有 HMM 方法都报；对 P1，它**不是**恒等式，只有先验边际才被反解强制对齐，见 §2.3；对 PD，先验边际只在首位等于 `ε̂_d`，之后向 `π*` 衰减）。
- **`seedbs` 用同一套评价**：IoU、any-FP、边界误差都由逐位置标签算，用与 HMM 方法相同的函数（`l0/metrics.py`）；配对 bootstrap 用同一组文章下标。只有 Rand index 用它自己的切换点（见上）。它没有 `ε̂` 与后验，次终点 4、5 不报。
- **结构终点**（不需要 test 显著性）：`â₀₀`、`â₁₁`、`π̂₁` 的点估计与 bootstrap 区间；`a₀₀=a₁₁` 的似然比检验；hist200、`param*`、ecdf400 在 `y∈[0.99,1]` 的密度与 `hist25` 之比；`f̂₀` 与 1 的距离。
- `full_wm` 单独报告，**不作主终点**：它的 truth 全为 1，IoU 就等于 recall，只反映"标得多"（[l0_review:19-20](l0_review_20261103.md#L19-L20)）。

### 6.3 判据（先写死）

判据只对主表四格设。

1. **误报**：四格各自在 `null_test` 上重校准后误报率的 95% 分位 ≤ 2α 且中位数 ≤ α（R1 口径）。单点 + Wilson 区间只作描述。
2. **非劣**：每一格对 `opt_hmm` 的 ΔIoU ≥ −0.01。
3. **连续性有效**：四格中任一格对 `independent` 的 ΔIoU 显著为正（配对 bootstrap 2000 次，95% 区间下界 > 0）。
4. **两条轴**：`π` 轴（同一 `f₁` 下 PD − PE，两组）与 `f₁` 轴（同一 `π` 下 `param*` − hist200，两组）的 ΔIoU，只报方向与区间，**不设显著性门槛**。`param*` 经过 7 选 1，hist200 没有（§3.1 的选择偏倚），报告里按"流程"措辞。附录里的比较（PE 对 P1 / P2、hist25 与 ecdf400 各一档、7 个参数族之间、`opt_hmm_li` 对 `pd_hist25` 等）一律只作描述（§6.5）。
5. **结构结论**：`a₀₀=a₁₁` 的似然比检验（约束 EM，§5.2）`p<0.05` 才声称"两状态保持率不同"；`â` 取到边界（0.50 或 0.999）时标注"边界受限"，不当结论。
6. **`seedbs` 不设判据**：四格与它的差距照实报告（ΔIoU 与区间），不据此判成败。若看过 `dev2` 后要加判据，须在 S4 之前另起版本写死；看过 test 后再定的，一律只作描述。

### 6.4 诊断

- **`f̂₀`**：`null_cal` 上同分箱密度，报 `sup|f̂₀−1|`，并按 `S2` 分桶报偏差。
- **`A` 的似然面与 EM 健康度**：网格给出的 `(a₀₀,a₁₁)` 剖面与平台范围；`ℓ_EM − ℓ_网格` 之差；各起点终点是否一致；`em_nonmonotone` 是否出现；重估前后 `Â` 的变化。
- **`ε̂` 估计器对照**：`ε̂_opt` 与旧估计器之差的分布；二者对真值的误差；`eps_boundary` 的比例。
- **`π` 的学习结果**：PE 的 `π̂₁` 及 bootstrap 区间，与各场景首位的真实水印占比对照（`switch` 首位为 0，`resample_*` / `seg*` 首位多为 1）；PE 的 `π̂₁` 与 P2 的 `π*` 之差。
- **PD 的首位先验管多远**：各族的 `λ̂ = â₀₀ + â₁₁ − 1` 与半衰期 `ln 2 / (−ln λ̂)`；PD 与同族 P2 标签不同的位置在篇内的分布（hist25、ecdf400 两族有 P2 可比），预期集中在开头；PD 与同族 PE 的 `τ` 之差（§2.3 的间接作用）。PD 的首位概率就是 `ε̂_d`，它的误差看上一项。
- **`seedbs`**：选出的 `(B, ζ)` 与 `c`，16 组在 `dev` 上的 IoU 面；`null_cal` 上每篇的假切换点数；`dev2` 上找回的切换点数与真值（`seg2/3/4` 分别 1 / 2 / 4 个）之比，及到最近真值切换点的距离；每篇耗时。
- **P1 对齐质量**（仅对照）：`ᾱ` 的值；`|先验边际均值 − ε̂_d|` 分布；`pi_clipped` / `pi_unidentifiable` 的比例。
- **nocap 旁支**：§3.5 列出的各项（密度上界、后验饱和、`τ` 退化、`Â` 的变化、`dev`/`dev2` 上的 ΔIoU）。
- **参数族**：7 个族在 `dev` 上的选择表（各自入选 `cap`、PD / PE 的 IoU、族得分、是否有资格）；同一张表在 `dev2` 上的 IoU（只描述，不用于选族）；拟合优度：calibration 分 2 折（50 / 50 篇）交叉，一折拟合、另一折算纯水印枢轴的平均对数密度，对 7 个族与 hist200、ecdf400 各报一次（只报，不用于选族）；各族 `y∈[0.99,1]` 的密度与 hist200 之比。
- **`ecdf400` 噪声**：calibration 分 2 折（50 / 50 篇）各拟一次，报两次 `f̂₁` 的 `L1` 距离。

### 6.5 明确不追求的

四格对 `fixed_e`（及 L0 的 `fixed_rho`）的 IoU 增益。理由：L0 的 Δ 在 ±0.02 且置信区间跨 0（[l0_review:13-14](l0_review_20261103.md#L13-L14)），而 `test=160`（每场景 40 篇）对这个量级没有分辨力；R4 已判"停止追"（[l0_review:67-68](l0_review_20261103.md#L67-L68)）。若出现大差异，先当作实现错误排查。

也不预设四格胜过 `seedbs`。事前判断是 `seedbs` 很可能更好，至少它不依赖 `f₁` 的估计，`f₁` 失配对它没有影响。差距照实报告；不为缩小差距而在看过 `dev2` 之后改四格的设置，要改须另起版本（§6.3 判据 6）。

## 8. 风险与预案

| 风险 | 表现 | 预案 |
|---|---|---|
| `A` 贴边 | `â` 取到 0.50 或 0.999，似然面有平台 | 报平台范围；不当结论 |
| `ε̂_opt` 对 `f₁` 失配敏感 | 混合文本里的备择分布与校准不同源，`ε̂` 系统性偏 | 报 `ε̂` 对真值的误差与旧估计器之差；PD 直接继承这个偏差（不放大），P1 会再放大（§2.3），所以不作为单独结论 |
| EM 局部最优 / 多峰 | 不同起点终点不同，或 `ℓ_EM < ℓ_网格` | 多起点取最优；网格最优点作起点；仍不满足就冻结网格值并标注（§5.2） |
| P1 / P2 的 EM 对 `π` 的近似 | 非严格单调（`em_nonmonotone`）；PE、PD 不受此影响 | 用精确前向似然监控，停在最佳步；PE、PD 的单调性在测试里单独验证 |
| PE 的 `π₁` 是各场景的折中 | `mixed_cal` 里 `switch` 首位为 0、`resample` 首位多为 1，`π̂₁` 落在中间；`seg*` 首位全为 1 | 报 `π̂₁` 与各场景首位真值对照；这是全局 `π` 的固有代价。PD 逐篇给首位、不放大误差，但依赖 `ε̂_d`；差别看主表的 PD − PE，不预设谁更好 |
| PD 与 PE 几乎没差别 | `λ̂` 小时 `ε̂_d` 的影响几个位置后就消失，两者标签几乎相同 | 这本身就是结论（首位信息对全篇作用不大）；报半衰期与标签差异的位置分布（§6.4），不为拉开差距改设定 |
| `A` 估不准 | `mixed_cal` 的切换次数仍少（50 篇合计约 300–600） | 按篇 bootstrap 给区间；区间跨度 > 0.1 就如实写"当前数据只能定到这个精度" |
| **P1（附录）放大 `ε̂` 误差** | `ᾱ` 小（链不够粘），`π_d` 大量被 clip 到 0 / 1 | 报 `ᾱ` 与 clip 比例；`ᾱ<0.05` 退回 P2；若多数文章退回，结论就是"P1 在此数据上不可用" |
| 非平稳漂移 | 后验 `mean γ` 系统性偏离 `ε̂_d` | 报 §6.2 次终点 5；偏离大本身就是结论 |
| ECDF 求导噪声 | 尾部密度锯齿 | 400 段 + 保单调；2 折稳定性；必要时降节点数 |
| `cap` 顶到网格上界（只对 ecdf400 启用幂律截断） | ecdf400 的最优 `K=1000` | ecdf400（附录）启用 `s` 尺度幂律截断（见 §3.3）；参数族只标注 |
| 参数族尾部拟合差 | 矩估计抓的是整体形状，尾部（`y→1` 的尖峰）可能偏低或偏高；`beta` 在 `y→1` 无界或过平 | 报 `y∈[0.99,1]` 的密度与 hist200 之比、2 折拟合优度（§6.4）；`cap` 兜住无界；差就如实写，不为参数族单独换估计法 |
| `param*` 选错 | `dev` 只有 30 篇，7 个族得分差距小于噪声 | 7 个族在 `dev2` 与 test 上全部报告（附录），不只报入选者；`dev2` 上的差距只作描述，不据此改入选 |
| 参数族之间几乎没差别 | 7 个族在 `dev` 得分接近，入选近乎随机 | 这本身就是结论（`f₁` 的具体族不重要）；并列规则按候选表顺序，写明 |
| nocap 旁支数值失控 | `g` 极大导致后验饱和、`τ=1`、或前向递推溢出 | 这正是旁支要记录的现象，照算照报；前向递推用对数空间 / 缩放，若仍溢出就记录溢出位置而不修补；不因此改主线 |
| `cap` 与 `τ` 共用 null | 误报被低估 | `cap` 只在 dev 选，`τ` 只用 `null_cal` |
| `A` 在临时 `cap=25` 下估、`cap` 选后才重估 | 选 `cap` 时用的 `A` 与最终 `A` 略有出入 | 只重估一次、不再迭代；报新旧 `Â` 之差；差得大就在报告里说明 `cap` 对 `A` 敏感 |
| `dev2` 太小 | 阶段结论不稳 | 只报方向与区间；显著性留给 S4 |
| `seedbs` 与论文不一致 | 不做钥匙对齐、用 iid `U(0,1)` 换钥匙、补段标签，`a`、`T′`、最短区间由我们定（§5.3） | 报告里称"按 1.pdf 适配"，不称"复现"；逐条列出改动；不与论文的数字直接比 |
| `seedbs` 计算量 | 每个区间要做 `T′=1999` 次自助，每次一遍 `O(l²)` 的 KS 扫描；`null_cal` 400 篇 × 4 个 `B` 都要跑 | KS 用计数恒等式并向量化；窗口 p 值与 `p̃` 只依赖 `B`，四档 `ζ` 共用；报每篇耗时；`T′` 不降到 1000 以下（否则 `ζ=0.001` 那一档失效，§5.3） |
| 多重比较 | 30 方法（主表 5 条：四格 + `seedbs`；附录 25 条）× 7 场景 | 主终点单一；判据只对四格设，附录与 `seedbs` 只作描述；阶段比较只对 `dev2` 报"探索性" |
