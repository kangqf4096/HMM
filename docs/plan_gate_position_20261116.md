## 1. 为什么改

1. **τ 一身二用。** 现行 τ 取 `null_cal` 上每篇最大后验的 95% 分位，同时用作文档阈值和逐位置阈值。它只约束 null 文档的 any-FP，从不约束水印文章内部 truth=0 位置的误报（下称 FPR₁）。
2. **FPR₁ 随偶然因素大幅摆动。**
   - l2q1：两篇单 token 死循环文章占住了 `pd_fe` 中 e=0.05 的核，null 文本的 E₀[log g]=−1.99，τ 被压到 0.25，FPR₁ 达到 0.60。
   - l2q1f（剔除这两篇后）：τ=0.91，规则转为过度保守（§3：`pd_m400` 在 dev 上召回只有 0.21–0.50）。
   - 两种情况下，FPR₁ 都是副产品，不是设计出来的。
3. 平均IoU对高误报率的方法惩罚不够，

**v1 中 null 文章只定阈值，不参与 f₁ 和 A 的拟合。** 模型把 f₀ ≡ U(0,1) 固定下来，`null_cal` 只用来诊断它。本次按文章聚类重算：

- Σz² = 254（自由度约 199），最大 |z| = 3.93；
- Y ≥ 0.99 那两个箱的合并密度是 1.04；
- 文章内相关只把标准误放大了 7%。

偏离很小，所以 v2 不估计 f₀。

**v2 同样不让 null 文章进入 A 或位置级校准：**

- **进入 EM。** PD 下 null 文章的 π_d = e′ ≈ 0，整篇都处在状态 0，只会把 a₀₀ 推向 1。推多少取决于 null 与混合文章的数量比，而这个比例是任意定的。“文章有没有水印”属于文档层的问题，交给门控处理。
- **进入位置级校准。** null 文章的每个位置都离水印很远，是最容易判对的负样本。混进去会摊薄 FPR₁，τ_pos 随之下降。null 文档上的误报已由门控定理控制住（L3 §2.2：any-FP ≤ α，FPR₀ ≤ α）。

### 3.4 结论（作为计划依据，不作结果报告）

1. **主要收益来自解耦。** 把逐位置阈值从 null 最大值上拆下来、改按 FPR₁ 校准后，`pd_m400` 在 dev 上：
   - paper 从 0.503 升到 0.723，alt 从 0.199 升到 0.396，r2 从 0.284 升到 0.596；
   - 代价是可分辨 FPR₁ 从约 0 升到 0.05–0.16；
   - null 的 any-FP 由门控 c 保持在 α 以内。
2. **β 是真正的旋钮。**
   - `pd_fe` 在 β=0.05 时 τ_pos=0.911，几乎等于 v1 的 0.910，规则没有变化；β=0.10 时才有收益。
   - 若用原始 FPR₁（d=0，含接缝后的位置和短间隙），β=0.05 时 τ 会升到 0.98（`pd_fe`）和 0.94（`pd_m400`），paper 只剩 0.44。所以约束必须用可分辨口径。
3. **τ 按 e′ 自适应，两种做法都没有收益。** G1 与 G2 都不优于 G0，各项差在 −0.06 到 +0.01 之间。G1 各层的 τ 也不单调（`pd_fe`：0.83、0.86、0.88、0.91、0.73）。
4. **γ 的校准度确实随 e′ 变化，只是这点信息不足以抵消分层带来的噪声。**
   - 同样是 γ ∈ [0.9, 0.99)，`pd_fe` 在五层中的真实水印比例分别为 0.47、0.68、0.78、0.85、0.74。
   - γ < 0.1 的位置里仍有 0.04–0.35 是水印。
   - FPR₁ 的差异主要来自场景：同一 τ_pos 下，alt 的 FPR₁ 是 paper 的 3–8 倍。e′ 层与场景是绑在一起的：低层主要是 alt 和 r2，高层主要是 Setting 3。若以后要做条件保证，分层变量应选与结构相关的量（如 γ 路径估计出的切换次数），而不是 e′。
5. **f₁(e′) 的价值要在同等 FPR 下重新评估。**
   - 同等 FPR 下，`pd_fe` 与 `pd_m400` 的 IoU 相当。
   - 看排序能力，`pd_fe` 在 r2 上明显更好（AUC 0.903 对 0.857），在 alt 和 r0 上更差。
   - 这与 L2 计划 §2 的机制假设一致：f₁(e′) 在熵选择性编辑上有用，在域外有代价。
   - v1 中 `fe` 的大幅领先，主要是阈值造成的。
6. **门控统计量用 e′ 还是 max γ，差别很小。** 例如 `pd_m400` 在 β=0.10 时，alt 为 0.396 对 0.379。原因是 dev 文章几乎都能被检出。
7. **平凡基线在 r2 上仍然最高（0.73），在 alt 上与最好的规则持平。** 只有 paper 类体现了真正的定位能力。

## 4. v2 判决规则

### 4.1 记号

- **e′_d：** 阶段 1 的 ε̂_opt，不变。
- **γ_t：** HMM 后验，不变。
- **可分辨负位置：** N_d = {t : truth_t = 0，且到最近 truth=1 位置的距离 > d}。离水印段 d 以内的 truth=0 位置（接缝后 4 位、短间隙、编辑点附近）不计入约束，但照常计入 IoU。
- **文章级可分辨误报率：** FPR₁ = |{t ∈ N_d : L_t = 1}| / |N_d|。只对 |N_d| ≥ m 的水印文章定义，m = 20。
- **判决：** L_t = 1{e′_d > c} · 1{γ_t > τ_pos}。

### 4.2 位置级阈值：conformal risk control

对 n 篇校准文章，单篇损失 ℓ_i(τ) = FPR₁ 随 τ 单调不增，且不超过 1。取

$$\hat\tau_{pos}=\inf\Big\{\tau:\ \tfrac{n}{n+1}\hat R_n(\tau)+\tfrac{1}{n+1}\le\beta\Big\},$$

其中 R̂_n 是这 n 篇文章 FPR₁ 的平均。若新文章与校准文章可交换，则 E[FPR₁] ≤ β（Angelopoulos et al., 2022, *Conformal Risk Control*, arXiv:2208.02814）。

**这个保证的适用范围要写明：**

- 它是对校准集场景构成的平均，不是逐场景的，更不是逐篇的；
- 换了编辑生成器，保证就不再成立（L3 §2.2 已指出）。

因此：

- 校准集的场景构成须与评价侧相同。汇总评价侧的 FPR₁ 时，按校准集的场景比例加权；
- R0 不进入校准，作为“未见生成器”的迁移检查。

### 4.3 文档门控 c

1. 先冻结 τ_pos。
2. 在 `null_cal` 上，若一篇文章按门内规则有被标记的位置，令 s_d = e′_d，否则 s_d = −∞。
3. 取 ĉ 为 s 的第 ⌈(1−α)(n+1)⌉ 小值，门控条件为 e′ > ĉ。

这样，null 文章的 any-FP ≤ α 有有限样本保证，FPR₀ ≤ α 也随之成立。τ_pos 不得使用 `null_cal`，否则两步不独立。

门控统计量：主方案用 e′，max γ（L3 的方案）作对照。HMM 对数似然比列为可选项，本轮不做。

### 4.4 参数（确认后写死）

- α = 0.05
- β = 0.10，敏感性取 0.05、0.20
- d = 10，敏感性取 5、20
- m = 20

β=0.05 时 `pd_fe` 与 v1 几乎相同（§3.4 第 2 条），所以主值建议取 0.10。β 代表“能接受多少文章内误报”，这个取舍需要我们自己定，数据给不出答案。

### 4.5 不采用的做法

- **G1、G2（τ 按 e′ 自适应）：** 依据 §3.2，不进入确认性评价。P0 正式版会在交叉拟合下复核一次；若结论翻转（交叉拟合下，dev 三类等权 IoU 比 G0 高 ≥ 0.02），另起版本。
- **null 文章进入 EM 或位置级校准：** 理由见 §2。

## 5. f₁(e′) 的稳健化（`fe`）

- **有效样本量按文章计。** n_eff^art(e) = (Σ_d w_d)² / Σ_d w_d²，其中 w_d 是文章 d 的核权重。
- **低 e 截断（方案 A）。** n_eff^art < 10 的格点不估计；e′ 低于最低合格格点 e_min 时，一律用 f₁(e_min)。这一条取代现在按位置计的 `min_neff=300`。l2q1f 的 e_min 预计在 0.2 附近，由 P0 复核。
- **单篇占比上限。** 报告每个格点上权重最大的单篇文章所占份额；份额 > 0.2 的格点视同不合格。
- 核形式、h 网格、cap 网格都不变；(cap, h) 在 v2 规则下于 dev 上重选。
- 有门控后，e′ ≤ c 的文章不打标签，低 e 端的核只通过 c 的校准间接起作用。稳健化主要是为了避免再出现 l2q1 那种一两篇文章决定一个核的情况。

## 6. 位置级校准用什么样本

### 6.1 需要什么

位置级校准需要的是**水印文章里离水印段足够远的 truth=0 位置**，而且场景构成要和评价侧一致。null 文章提供不了这些：它们的 e′ 中位数 0.0013，99% 分位 0.194，最大 0.261，也没有任何 truth=1 邻居。所以 null 文章只用来定门控。

### 6.2 现有训练侧的覆盖

表 4：d=10 时，可分辨负位置 ≥ 20 的篇数，按 `pd_fe` 的 e′ 分层。

| 角色 | [0, .3) | [.3, .45) | [.45, .6) | [.6, .75) | [.75, 1] | 合计 |
|---|---|---|---|---|---|---|
| `mix_splice` | 8 | 22 | 25 | 23 | 41 | 119 / 119 |
| `mix_alt` | 20 | 28 | 20 | 12 | 7 | 87 / 117 |
| `mix_r2` | 6 | 17 | 21 | 6 | 4 | 54 / 237 |
| 校准合计 | 34 | 67 | 66 | 41 | 52 | 260 |
| `dev`（评价用） | 14 | 22 | 25 | 28 | 19 | 108 / 149 |

- G0 有 260 篇可用，CRC 的有限样本代价 1/(n+1) ≈ 0.004；分成两半后 τ_pos 仍然稳定（§3 设置）。**G0 不缺样本。**
- r2 的负位置大多挨着编辑点：d=0 时有 231 篇 r2 文章的负位置 ≥ 20，d=10 时只剩 54 篇。alt12 的间隙只有 16 个位置，d=10 时没有可分辨负位置。

### 6.3 结论

- **主线不需要新的场景类型。** 现有的 splice、alt、r2 与评价侧同构，样本量也够。训练侧按 prompt 分 5 折交叉拟合：每折用其余 4 折拟合 A（`fe` 还要拟合核），在留出折上计算 γ，汇总后做 CRC。最终模型用全部数据拟合，与各折模型不完全相同，所以保证是近似的。
- **可选：独立的 `pos_cal`，用来让保证变成精确的。** 训练侧新增角色，用密钥 K1、新 prompt，每个 prompt 只做一种构成，不参与 f₁、A 的拟合和任何选择。配方与评价侧同构：Setting 2/3/4 各 30 篇，交替四档各 15 篇，r2_0.1、r2_0.3 各 15 篇，共 180 篇，约 330 次生成请求。
- **暂不做：`gap` 族（份额可变的拼接）。** 用 1–2 个 U 块替换 W，份额在 0.15–0.95 之间均匀取，块的位置按篇随机，每块至少 30 个位置。它能让每个 e′ 层都有长间隙，把 e′ 和场景拆开，但只有在做 e′ 条件保证时才需要；而 §3.2 显示这条路目前没有收益。

## 7. 评价与判据（预注册）

### 7.1 方法

**主方案 v2-H：** 门控 e′ + G0，分别接在 `pd_m400` 和 `pd_fe`（稳健化后）上。两个臂都报告。主判据 D3 用 P0 正式版选出的那一个（§9 的规则），另一个只作描述。

**对照：**

- v1：l2q1f 的冻结规则，原样使用；
- 平凡基线：v1 检出即整篇全标；
- SeedBS-v1：l2q1f 冻结；
- SeedBS-v2：用同一个 e′ 门控，对 `segment_scores` 做同样的 CRC 校准。
  - SeedBS 的位置分数和 γ 走同一套 `decide`，可以直接套用，只需要在校准文章上对选定的 B 做一次 precompute。
  - 另报 SeedBS 用它自己的 max 分数作门控的版本。

**消融：** 门控用 e′ 还是 max γ；`fe` 对 `m400`；β 和 d 的敏感性。

**精简：** v2 只保留 PD。m100 和 PE 回答的问题在 L2 中已经回答过，而且 PE 在 dev 上一直不优于 PD。

### 7.2 终点

- **主终点**（按块报告）：
  - paper、alt、r2、r0 的 IoU，与平凡基线并列；
  - 可分辨 FPR₁（d=10）；
  - 召回。
- **文档级：** `null_test` 上的 any-FP，带 Wilson 区间。
- **次终点：**
  - 精确率、原始 FPR₁（d=0）、Rand index；
  - Setting 1 的召回、边界误差；
  - 被门控挡掉的水印文章数及其真值 ε。
- 所有差值都用文章级配对 bootstrap（2000 次）。

### 7.3 判据

| 编号 | 内容 | 性质 |
|---|---|---|
| D1 | `null_test` 上 any-FP ≤ α（沿用 C1 的重校准口径：p95 ≤ 2α，中位 ≤ α） | 门槛 |
| D2 | paper、alt、r2 汇总的可分辨 FPR₁ 均值（按校准集的场景比例加权）：95% 区间下界 ≤ β | 门槛：成立才能说“文章内误报受控” |
| D3 | v2-H − v1 在 paper 块的 ΔIoU：区间下界 > 0 | 门槛：成立才能说“v2 改进了定位” |
| D4 | r0 块（未参与校准的生成器）的可分辨 FPR₁ | 只报；若区间下界 > β，写明“保证不能迁移到未见的编辑方式” |
| D5 | v2-H 相对 SeedBS-v2、相对平凡基线，各块的 ΔIoU | 只报 |

alt、r2、r0 块的 IoU 一律与平凡基线并列报告，不能只凭这三块的 IoU 声称定位改进。

## 11. 风险

| 风险 | 表现 | 预案 |
|---|---|---|
| FPR₁ 依赖生成器 | r0 或新结构上 FPR₁ 超过 β | D4 如实报告；只声称对校准构成成立 |
| 场景间 FPR₁ 差异大 | alt 远高于 β，paper 远低于 β | 按块报告；平均意义上的保证照实描述，不说成逐块的 |
| d 决定了估计量本身 | 结论随 d 变化 | 主值 d=10 写死，另报 5 和 20 |
| r2、alt 的 IoU 偏向整篇全标 | 受控规则看起来输给平凡基线 | 并列报告平凡基线；门槛判据只放 paper 块 |
| 门控挡掉弱水印文章 | e′ ≤ c 的水印文章 IoU=0 | 报告被挡篇数及其真值 ε |
| 交叉拟合只给出近似保证 | 实际 FPR₁ 略高于 β | D2 检验；需要精确保证时生成 `pos_cal` |
| test 复用 | 在 l2q1f test 上调参 | 确认性结论只用 K3 |
| 计算量 | SeedBS-v2 需在约 260 篇校准文章上 precompute；每个方法交叉拟合要多做 5 次 EM | 只对选定的 B 做；复用缓存 |
