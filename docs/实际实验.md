# 1. 项目主线

**问题。** 拿到一段文本，知道检测用的密钥，但不知道哪些位置带水印。要做的是：判断整篇有没有水印、估计带水印的比例、把文本切成“无水印片段”和“有水印片段”。

**性质。** 这是**外置的统计后处理**：检测端只用密钥和 token 序列算出每个位置的枢轴统计量 Y_t，再用统计方法判断位置。它不改模型、不训练任何大模型，LLM（OPT-1.3B）只用来**生成实验数据**，检测算法本身不调用 LLM。我们研究的是“检测者如何利用已有的枢轴统计量定位”，不是设计新水印或新枢轴（与 `问题设置.md` 第 5 行一致）。

**当前流水线**（每一步对应代码模块）：

```
密钥 + 前 4 个 token ──> Y_t ∈ (0,1)                  protocol.py / generate.py
        │  无水印: Y_t ~ U(0,1)，即 f₀ = 1
        │  有水印: Y_t 偏向 1，形状 f₁ 未知
        ▼
① 用“纯水印校准文章”估计 f₁                           emissions.py（直方图）/ parametric.py（参数族）
② 逐篇估计水印比例 ε（边际复合似然）                    proportion.py
③ 两状态 HMM：π=(1-ε, ε)，A=ρ·I+(1-ρ)·1·π
   ρ 从候选集 {0,.5,.8,.9,.95,.98,.99} 按前向似然选      detector.py / hmm.py
   前向—后向得到每个位置“有水印”的后验 γ_t
④ 用独立“无水印文章”校准阈值：对每篇取 max γ_t，取分位数   calibration.py
   超过阈值的位置标为水印，相邻位置合并成片段
        ▼
IoU / F1 / ε 误差 / 无水印文章 any-FP                    metrics.py
```

和 `问题设置.md` 的对应关系：观测是 Y_t，状态是 0/1，f₀、f₁ 是两种状态下的观测分布，初始分布与转移矩阵由 ε 和 ρ 给出。我们的转移矩阵多了一个“持续性”参数 ρ：ρ 越大越倾向保持原状态，ρ=0 退化为各位置独立的混合模型。

# 3. 分层实验方案

每一层只改一个东西、回答一个独立问题，下层结论不依赖上层。这样任何一层失败，都能定位到具体假设。

| 层 | 改什么 | 回答的问题 | 需要什么 |
|---|---|---|---|
| **L0 主线** | f₁ 的估计方式 | 直方图与参数族，哪个更好 | 只要 Y，**不要模型、不要重放** |
| **L1 附加** | 额外信息源 | 给检测器更多信息能多拿多少 | 需要重放 P_t 或 S2 |
| **L2 评估** | 评估与统计 | 结论稳不稳、差多少 | 只要已有输出 |

L0 的结论最硬，因为它不依赖任何重算或模型假设；L1、L2 的争议不会污染 L0。

## L0：你们设想的主线

只有一个变量：**f₁ 用直方图估计，还是用参数族估计**。其余固定：Y 的构造、ε 的估计方式、HMM 加 ρ 选优、阈值校准方式、四个对照方法。

| 族 | 拟合对象 | 参数 |
|---|---|---|
| `histogram`（现状基线） | y | 25 箱 |
| `beta` | y | a, b |
| `beta_mixture` | y | 3 分量 EM |
| `truncnorm` | y | μ, σ |
| `logitnorm` | logit(y) | μ, σ |
| `gamma` | X=-log y | k, θ |
| `weibull` | X | k, λ |
| `lognormal` | X | μ, σ |

指标只报四个：mean IoU、F1、ε 误差、无水印文章 any-FP。

**一个必须知道的限制**：所有配置里纯水印校准文章只有 **8 篇**（约 1000 个 Y），`text_null256/1024` 只增加了 null 文章数。所以 L0 的“直方图 vs 参数族”目前是**小样本比较**，参数族在此规模下是否占便宜，需要看结果，不能预设结论。

## L1：我们加的实验（不是你们的设想）

| 子层 | 额外信息 | 方法名 | 依赖 |
|---|---|---|---|
| L1a | 按 S2 分层（S2=Σ P_w²，当前位置“选词有多集中”） | `s2_histogram`、`s2_{family}` | 重放得到 S2 |
| L1b | 解析 f₁(y\|P)=Σ y^(1/P_w−1) | `raw_analytic`、`clip_ln3/4/6` | 重放得到 P_t |
| L1c | 带原始 prompt 重算的评估上下文 | `model_context` | 重放 |
| L1d | 原始历史对齐（oracle，仅作上界） | `source_alignment` | 重放加真值对齐 |

L1 的目的：**弄清“多给检测器信息能换来什么”**，同时暴露代价（重放误差、S2 分层的混合偏差、截断超参）。这些方法用了 prompt，L1d 甚至用了真值对齐，**不能当成无需 prompt 的检测性能**。

## L2：评估与统计

按完整文章做配对 bootstrap；同一长度内，用测试文章的最大分数对 null 测试文章算 PR-AUC（`tmp/scale_eval_parametric.py`）；null 文章 any-FP 附 Wilson 区间。

# 4. 我们发现的问题

## 4.1 似然比爆炸与截断（最重要）

**现象。** `docs/algorithm.md` 记录了一次真实服务器实验：解析发射 f₁(y|P) 在**无编辑**文本上不比经验直方图差，但**编辑后全面输给直方图**。HF 与 vLLM 的概率重算误差很小（S2 绝对差均值 4.4e-4，最大 9.2e-3），解释不了差距。我们的判断是：**无界的似然比和 max-score 阈值校准相互放大**。这是判断，不是已经逐项隔离的结论。

**为什么会爆炸。** 对一个位置 P=softmax(logits)，水印下 Y 的密度是 f₁(y|P)=Σ_w y^(1/P_w−1)。

- **上端（y→1）**：f₁(1−δ|P) ≈ #{w : P_w ≳ δ}，也就是“概率不小于 δ 的 token 个数”。上界是有效词表大小（约 5×10⁴），但达到上界需要 1−y 小于最小的 P_w。
- **下端（y 小）**：平坦的 P 下 log f₁ 非常负，代码里把 log 密度下限设为 −700 防止 exp 下溢。下溢成 0 会触发 `infer_ratios` 里 g>0 的断言，在 HMM 里则相当于对“有水印”状态一票否决。
- **对 P 敏感**：上端取决于 P 的**尾部有多少 token**。CDF 对 P 稳定（TV 界）不蕴含密度比稳定，所以 vLLM 与重放的尾部差异、编辑后前缀变化，会直接改变这个计数。

**我用一个玩具计算核对了数量级**（`python tmp/lr.py`，词表 50272，Zipf 型尾部，**不是真实 OPT 分布**，只能说明量级和机制）：

| 1−y | f₁(y\|P) 的量级 | H1 下 Y 落在 1−δ 之内的概率 |
|---|---|---|
| 10⁻² | 8–10 | 30%–80% |
| 10⁻³ | 50–100 | 14%–61% |
| 10⁻⁴ | 200–900 | 6%–41% |
| 10⁻⁶ | 5×10³–4×10⁴ | 1%–4% |

关键含义：**水印位置的 Y 经常就落在极靠近 1 的地方**。原因是选中低概率 token 时，Y|W=w ~ Beta(1/P_w, 1)，即 Y=U^(P_w)，P_w 越小 Y 越贴近 1。所以信息集中在 1−y 的**对数尺度**上，而不是“Y 大”这么粗。

**这几处和我们之前的口头说法不一样，已更正**：

- 之前说“经验分布看不到尖峰，因为命中概率约 10⁻⁴”——不成立。玩具计算里水印位置落进尖峰区并不罕见。25 箱直方图是**把尖峰压成最后一箱**（密度 ≤25），不是看不到。
- 之前说“log f₁ 低到 −10⁵”——玩具计算里 y=0.01 时约 −7 到 −48，−700 是代码的下限保护，不是实测范围。

**截断改变了什么。** 截断 min(log f₁, K) 是单调变换，所以：

| 检测方式 | 影响 |
|---|---|
| 单点排序（ROC / AUC） | 完全没有影响 |
| 多点聚合（HMM 后验、Σ log f₁、窗口平均） | 完全改变，因为聚合用的是相对强度 |

硬截断还在 K 处造出点质量：超过 K 的位置被压成同一个值，它们之间的次序信息丢失。这是信息损失，不是平滑。

**两个要分开的“上界”。**

| 估计方式 | y→1 的行为 | 是否天然有界 |
|---|---|---|
| histogram（B 箱） | 最后一箱密度 ≤ B | 有界，上界 ≈ B，改箱数就改上界 |
| beta(a,b) | b>1→0；b=1→a；b<1→∞ | 取决于拟合的 b |
| beta_mixture | 任一分量 b<1 即发散 | 取决于 EM 结果 |
| truncnorm | 在 (0,1) 上截断 | 有界 |
| logitnorm | 密度 →0 | 有界 |
| gamma（X=-log y） | k>1→0；k=1→1/θ；k<1→∞ | 取决于 k |
| weibull（X） | k>1→0；k<1→∞ | 取决于 k |
| lognormal（X） | X→0 时密度 →0 | 有界 |

参数化不会自动让上端有界，只是把“上界从哪来”从箱数转移到族的尾部指数。注意 y→1 对应 X→0，所以 X 族（gamma、weibull、lognormal）在 1−y 的小尺度上分辨率更好；而按玩具计算，真实的 f̄₁ 在 y→1 处很可能是**被词表大小截断的幂律**，也就是 k<1 的发散在这里可能是对的，不是缺陷。这一点**还没有真实数据验证**。

**处理路线（动机分两件事，不要混为一谈）：**

- L0 加统一 `cap`：让各族**可比**。不加的话比较的是“族 + 各自隐含截断”，加了才是纯族差异。
- L1b 用 `clip`：压住**真实**的尖峰，避免 P̂ 稍有误差就让单点后验饱和。
- 终点：让上界从“可调超参”变成“模型本身的自然结果”。一个**尚未实现**的想法是在 −log(1−y) 尺度上分箱，让密度在近 1 处有足够分辨率又自然有界。

**待测**：对每个族报告校准集上的 max f₁，以及 y 的 p99.9 / p99.99 分位处的密度；若某族的外推 max f₁ 远大于 B，它在整篇评估上就有失控风险。同时对真实 OPT 的 f̄₁ 画 −log(1−y) 尺度的直方图，检验“幂律加截断”的假设。

## 4.2 Z=1 不等于 P 不变

Z=1 只说明水印的随机量还能恢复（前 4 个 token 没变），**不说明模型的下一词分布没变**。P_t 依赖整个前缀，seed 只依赖最近 4 个 token。实测（`docs/algorithm.md` 引 `runs/piv-ax01-diag/report.md`）：seed 保留的编辑位置上，生成时与重算的 P 的 TV 仍有 0.12–0.34（replace 0.3 最长尾处最大 0.97）。

后果：`source_alignment` 把“原始位置套用原始历史的 P”当作 Z=1 的代理并不可靠，replace 0.3 下有 77% 的位置是 Z=0 却被当作有信号。

## 4.3 校准迁移与“比例 / 强度”混淆

用校准集估的 f̄₁ 去检测测试文本，只有两者的“条件构成”相同才成立。反例（`docs/alternative_distribution_properties_20261027.md` §5.3）：测试里全部位置都有水印，但只有比例 a 使用强条件，其余是几乎确定的弱条件。用校准的强信号 f₁ 拟合，得到 ε̂≈a，而实际水印比例是 1。这是分布失配，样本再多也不解决。

## 4.4 ε 端点会让 HMM 塌缩

当前允许 ε=0 或 1。此时 π 退化为单点，平稳 HMM 被压到单一状态，看到数据后也无法重新打开另一状态。这是两阶段（先估 ε 再推断状态）的结构性局限，代码里没有用隐藏的截断绕开，需要靠评估看实际影响。另外 ε 是**边际复合似然**的拟合值，不是联合 HMM 的 MLE。

## 4.5 null 不是人工文本

目前所有“无水印”样本是未加水印的 OPT 续写，不是人写的文本。在理想假设下两者的 Y 都服从 U(0,1)，但人工文本可能有重复片段、公式占位符（@xmath、@xcite）等，需要实测。`问题设置.md` 要求的“人工文本”数据来源，我们还没有真正用上。

## 4.6 其他需要诚实说明的限制

- 相同的上下文会复用同一随机向量，Y_t 在理想假设下独立，实际不严格独立；HMM 的乘积似然是工作近似。
- null 校准只控制“**无水印整篇**至少被错报一个位置”的概率（any-FP），**不提供混合文本的 FDR 或逐位置置信保证**。
- smoke / pilot 的 null 文章太少（32 或 128），不足以验证 5% 的真实误报率；正式实验建议各 2000。
- `docs/validation.md` 里的 Markov 小试结果只证明流程跑通，不能据此声称 opt_hmm 优于固定比例的 HMM。

# 5. 整文档评估与定位：双目标，各选一个方法

**状态：这一节是正在讨论的方案，尚未决定。** 下面的候选方法都来自 `papers/` 里已有全文，具体取舍的证据读完后再写入。

两个目标需要的信息和错误率口径不同：

| | **A. 整文档评估** | **B. 定位** |
|---|---|---|
| 问什么 | 这篇有没有水印、占比多少 | 哪些位置有水印 |
| 输出 | 文档级统计量或决策，ε̂ | 逐位置后验或标签，片段区间 |
| 错误率口径 | 无水印文章的整篇误报；ε 误差 | IoU / F1、片段边界误差；若用 SPOT 则 mFDR |
| 难度 | 较容易 | 严格更难（SPOT 证明：能检测不代表能定位） |

当前代码里两者**共用同一条流水线**：ε̂ 是 A 的副产品，整篇判定靠 B 的最大后验阈值，并没有为 A 单独设计检测统计量。

**候选方法：**

| 目标 | 候选 | 需要什么 | 本地全文 |
|---|---|---|---|
| A | 现有：复合似然 ε̂ + max-score any-FP | f₁ | 本项目 |
| A | OPT 的 initial / refined / optimal 比例估计 | F₀，以及开源模型上的纯水印 CDF（refined） | `papers/text/2506.22343v1_proportions.txt` |
| A | Tr-GoF 整篇检测 | 分布已知的噪声，对编辑稳健 | `papers/text/2025_jrssb_robust_edits.txt` |
| B | 我们的 HMM（`opt_hmm`），利用相邻位置的连续性 | f₁（估计得到） | 本项目 |
| B | SPOT 自适应尾阈值：用“期望 null 尾部数 / 实际尾部数”选阈值，逐点判断 | 只要 f₀ 的尾概率和存活比例估计，**不需完整 f₁** | `papers/text/2608.14906v2_localization.txt` §3.2 |
| B | 变点分段（Segmenting / Adaptive） | 随机化检验，自适应得分 | `papers/text/segment_existing.txt`、`2511.06645_adaptive_segment.txt` |

**选择依据（建议按这几条表决）：**

1. **能否回答主问题**：`experiment_plan_v1.md` 的第一个问题是“利用相邻位置信息，能否在相同的无水印整篇误报约束下改善定位”。HMM 对 SPOT 正好隔离“连续性”这一个因素。
2. **信息需求是否可比**：HMM 要估 f₁，SPOT 不要；二者对 prompt、重放的依赖也不同。
3. **错误率口径要统一**：SPOT 原文控制 mFDR，它公开的评估还有按经验逐 token FPR 选参数的做法；我们必须按 `experiment_plan_v1.md` 的要求，在开发集冻结参数、用独立 null 文章重新校准 any-FP，才能和 HMM 公平比，不能照搬 SPOT 原评估。
4. **理论保证不能互相借用**：SPOT 的最优性只在其论文指定的枢轴规则类和渐近设置里成立，不能无条件推广到 HMM。

**我的倾向（供讨论，不是定论）：** B 目标用 HMM 与 SPOT 对比；A 目标把现有 ε̂ + max-score 作为基线，与 OPT 的估计器、Tr-GoF 对照。
