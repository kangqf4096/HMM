## 1. 要回答的问题

- **QS（强度标尺）**：`fe` 用 e′ 给每篇文章选 f₁ 的核。e′ 混了水印占比 ε 和文章信号强度 s（诊断 §9：ε̂≈ε·s）。换成别的强度标尺，定位会不会更好？
- **QR（位置规则）**：现在 τ 同时当文档阈值和逐点阈值。先用文档门控把第一类错误管住，门内换别的逐点规则，IoU 能否提高、代价多大？
- **QF（逐位置误报）**：把"逐位置误报 ≤ 5%"作为约束，能做到多少召回？它和 any-FP 是什么关系？

## 2. 术语与依据

### 2.1 观测与似然比

- **观测是连续的 Y_t∈(0,1)，不是 0/1。** 实现上落进 200 个等宽箱，f₁ 是分段常数的直方图密度，所以实际上是 200 级的离散观测。阈值和 0/1 只出现在最后的判决里，不进入模型。
- **为什么只用似然比 g_t=f₁(Y_t)/f₀(Y_t)。** 前向后向里，在同一位置把两个状态的发射密度同乘一个常数，这个常数在归一化时消掉，γ 不变。所以 γ 只依赖比值。H₀ 下枢轴均匀，f₀≡1，于是 g=f₁。g 也是单点的 Neyman–Pearson 统计量。cap 把 g 截断到上限，限制单个位置的影响。

### 2.2 门控定理（两层判决的依据）

设文档判决为 D=1{T(Y)>τ_doc}，逐点标签为 L_t=D·r_t，其中 r_t 是任意门内规则。对 null 文章：

1. {存在 t 使 L_t=1} ⊆ {D=1}，所以 any-FP ≤ P(D=1) ≤ α；
2. 逐位置误报率 E[Σ_t L_t]/n ≤ P(D=1) ≤ α。

也就是说，只要文档门控在 null_cal 上校准，门内规则可以随便换，**null 文章上的 any-FP 和逐位置误报都自动 ≤ α**。门内规则的代价只体现在**水印文章里 truth=0 的位置**上。这部分没有任何零分布可以校准，只能在带标签的合成混合文章上估计，而且它依赖编辑生成器。

现行做法是 r_t=1{γ_t>τ_doc} 的特例。

### 2.3 逐位置误报的两种含义

| 记号 | 定义 | 能否用 null 校准 | 说明 |
|---|---|---|---|
| FPR₀ | null 文章里被标记位置的比例 | 能 | 不加门控时卡 5%，每篇 496 个位置平均误报约 25 个，any-FP 接近 1（m400 在 τ=0.25 时 any-FP 已达 0.905）；加门控后自动 ≤ α |
| FPR₁ | 水印文章里 truth=0 位置被标记的比例 | 不能 | 受相邻水印段平滑影响；只能在合成混合上估计；QF 真正关心的是它 |

### 2.4 LIS（Sun & Cai 2009）

把 LIS_t=1−γ_t 从小到大排序，取最大的 k 使前 k 个的平均值 ≤ α，标记这 k 个位置。被标记集合的平均 LIS 就是期望的假发现比例。阈值逐篇不同。理论保证要求 γ 校准、模型正确，而且是很多文章汇总意义上的 mFDR；单篇内只有近似意义。

### 2.5 期望 IoU 的 top-k

若 γ 校准，对固定 k 取 γ 最大的 k 个位置，用比值近似

$$\mathbb E[\mathrm{IoU}_k]\approx\frac{\sum_{\text{前 }k}\gamma_t}{k+\sum_{\text{其余}}\gamma_t}$$

取使它最大的 k。不需要阈值，逐篇自适应。

### 2.6 Viterbi

在对数空间求 argmax_z P(z|Y)：

$$\delta_t(j)=\max_i\big[\delta_{t-1}(i)+\log A_{ij}\big]+\ell_j(Y_t),\quad \ell_0=0,\ \ell_1=\log g_t+b$$

初值 δ₁(j)=log π_j+ℓ_j(Y₁)，记录 argmax 后回溯。两状态时它等价于带惩罚的变点检测：每次切换罚 −log(1−a)，段内收益是 Σ(log g_t+b)，与 seedbs 同类。偏置 b≤0 控制保守程度。

## 3. 数据与划分

- **训练侧**：l2q1 的 `l2q1-train-pos`。先按 `l2/degenerate.py` 的规则剔除退化文章（训练侧 7 篇）。
- **选择用交叉验证，不只用 dev。** dev 只有 150 篇，而且已经用来选过 cap 和 h。把 mix_r2、mix_splice、mix_alt、dev 共 630 篇带标签的混合文章按 prompt 分成 5 折（固定种子）。每折：
  1. 用 cal_pure 和**训练折**里 mix_r2 的 truth=1 位置拟合核；
  2. 在训练折的混合文章上跑 EM 得到 a₀₀、a₁₁；
  3. 在 null_cal 上校准 τ_doc（和需要它的 b）；
  4. 在留出折上评价。
- **CV 指标**：paper、alt、r2 三类 IoU 的等权平均，与 dev 的口径一致。mix_r0 只作机制对照，不进 CV 平均，单独报。
- **null_cal 不分折**：它不带标签，只用来校准门控，所有折共用。

## 4. 强度标尺候选（QS）

核的索引变量 v_d 在训练和推理时用**同一个函数**从整篇文章的 Y 计算。除 S0 外，都先用训练文章的 ECDF 变换到秩 [0,1]，让同一组 h 在各变量间可比。

| 代号 | v_d | 说明 |
|---|---|---|
| S0 | e′（原值） | 冻结方案，基线 |
| S0r | e′ 的秩 | 区分"变量"和"秩变换"的影响 |
| S1 | 平均 Y 的秩 | 已有小样本结果 |
| S2 | mean(−log(1−Y)) 的秩 | 偏重尾部，接近 Aaronson 统计量 |
| S3 | P(Y≥0.99) 的秩 | 只看尾部 |
| S4 | 两遍段内强度：先用 S0 跑一遍得到 γ，再算 Σγ_t·h(Y_t)/Σγ_t，h 为 −log(1−Y)，取秩 | 只用疑似水印位置估计强度，是唯一试图拆开 ε 和 s 的候选 |
| S−  | 打乱的 e′ | 阴性对照 |
| S★ | 用真值算的段内 mean(−log(1−Y)) | **oracle 上界，只用于评价**，不作候选 |

S1、S2、S3 都是边缘分布的函数，同样混杂了 ε 和 s，预期和 S0 差不多。S4 是否更好，直接检验"段结构能否帮助识别 s"这一推理（不可识别性讨论见 `汇报.md` §9）。

**超参**：h∈{0.05, 0.1, 0.2}，cap∈{5, 10, 25}。每个 (S, h) 在每折重新跑 EM（cap 取 25，与 `tmp/fy.py` 一致）。

## 5. 位置规则候选（QR、QF）

除 R0 和 R4a 外，都在同一个文档门控之内：门控统计量用现行的 max γ，τ_doc 取 null_cal 的 95% 分位。

| 代号 | 门内规则 | 自由参数与选法 |
|---|---|---|
| R0 | γ_t>τ_doc（现行） | 无 |
| R1 | γ_t>0.5 | 无（γ 校准时，这是 Hamming 损失下的贝叶斯规则） |
| R2 | γ_t>c | c∈{0.1, 0.2, …, 0.9}，在 CV 训练折上选 |
| R3 | LIS，水平 α_L | α_L∈{0.05, 0.1, 0.2}，在 CV 训练折上选 |
| R4a | Viterbi + 偏置 b，**不另加门控**：路径里出现 1 即判有水印 | b 在 null_cal 上取，使 any-FP≤5% |
| R4b | 门控 + Viterbi（b=0） | 无 |
| R5 | γ_t>c_F，c_F 是在 CV 训练折的门内混合文章上使 FPR₁≤5% 的最小 c | 无（由约束决定） |
| R6 | 期望 IoU 的 top-k（§2.5） | 无 |

R5 回答 QF。另外报一个**不加门控**的对照 R5₀：c 取 null_cal 位置上 FPR₀=5% 的分位，只报它的 any-FP 和召回，用来说明这个约束为什么太松，不作候选。

**校准诊断 D1（先于 R1、R3、R6 做）**：在 CV 留出折上画可靠性图，即按 γ 分 10 档对比真实水印比例，并按 e′ 三档、离首尾距离（<20 / ≥20）分组。若 γ 明显失准，加一个变体 R1c：在训练折上用保序回归把 γ 映射成 P(truth=1|γ)，再用 R1 / R3 / R6。这是"阈值随位置变"的低自由度版本。

## 6. 指标

- **主指标**：IoU（按类别和块）。
- **次指标**：
  - 位置召回、FDR；
  - FPR₁（混合文章 truth=0 位置的误报率）；
  - null 的 any-FP 和 FPR₀；
  - Setting 1 的假切换点数；
  - 边界误差。
- **对比**：配对的文章级 bootstrap（2000 次），给 95% 区间。对照对象是冻结的 pd_fe（S0 + R0）和 seedbs。

## 7. 流程与判据

### 7.1 阶段 A：强度标尺（规则固定为 R0 和 R2）

对每个 S 按 §4 选 (h, cap)，用 CV 平均 IoU 比较。

- **判据 A1**：最佳候选 S 相对 S0 的 CV IoU 配对差 ≥0.02，且 95% 区间下界 >0，才采用；否则保留 S0。
- **判据 A2（机制）**：S− 回到 m400 水平（与 `tmp/fy.py` 一致），S★ 给出上界。若 S4 与 S★ 的差距比 S0 与 S★ 的差距缩小一半以上，就记为"段结构对识别 s 有帮助"的支持证据。

### 7.2 阶段 B：位置规则（在阶段 A 选定的 S 上做，并在 S0 上重复一遍以便归因）

先做 D1，再跑 R0–R6。

- **判据 B1**：门内规则相对 R0 的 CV IoU 配对差，区间下界 >0 才算改进。
- **判据 B2**：门内规则（R1–R3、R4b、R5、R6）在 null_cal 上的 any-FP 由门控定理保证，只核对是否与 R0 相同。R4a 的 any-FP 须 ≤0.05，在 null_cal 上校准，在 null_test 上报。
- **判据 B3（QF）**：报 R5 下 FPR₁ 的实际值、召回和 IoU。若 R5 的 IoU 不低于 R0，就把"门控 + FPR₁≤5%"列为备选主方案。

### 7.3 阶段 C：确认

最多冻结 3 个组合：阶段 A 最优 S 与阶段 B 最优规则的组合，再加两个对照。

- **选项 1（确认性）**：用新密钥 K3 和新 prompt，按 test_a、test_b、null_test 的配方重新生成评价侧，规模同 l2q1，需要 GPU。结论按预注册判据报。
- **选项 2（探索性）**：只在已看过的 l2q1 test 上跑，结果标为【探索】。

**待定：** 选哪个取决于 GPU 预算，由用户决定。

## 8. 不做的

- 更多隐状态（句子类型）：没有带这种结构的真实编辑数据，先记下。
- 逐篇自由估计转移矩阵：单篇切换次数太少，不稳定（`汇报.md` 讨论）。如需要，只做 Beta 先验的 MAP，放到下一轮。
- 已知模型的条件 f₁（f₁(y|w)=y^{1/p−1}/p）：超出"检测者只看到 Y"的设定，以后单独讨论，包括它的偏差怎样刻画。
- 文档门控统计量的替换（如 HMM 对数似然比）：本轮固定为 max γ，只改门内规则，保证归因清楚。
