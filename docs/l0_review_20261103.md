# L0 第一轮判读与口径修订（2026-11-03）

判读对象：`runs/l0full0-eval`（histogram + beta，cap = 25）、`runs/l0full0-eval-nocap`（beta_nocap，附录）、
两份报告的 `frozen.json`，以及 `src/opt_hmm/l0/` 的实现。数据来自 `runs/l0full0-pos`。

**本文件写于看到 test 数字之后，因此只能作为下一轮的预注册修订，不能追溯用于本轮结论。** 本轮
"8 格全部未通过"的判定按原口径成立，不得改写。

## 1. 结论

1. **连续性先验有效。** switch 上 opt_hmm 比 independent 高 +0.295（hist）/ +0.346（beta），
   配对 bootstrap 区间下界 0.26。这是全部结果里唯一效应量远大于噪声的一项。
2. **"逐篇估 ε、逐篇选 ρ"没有可检出增益。** 对 fixed_e / fixed_rho / window 的 Δ 全部在 ±0.02 内且
   CI 跨 0。HMM 的收益来自"用了连续性"，不来自"参数估得准"。
3. **8 格全灭中有 2 格只卡在 any-FP 的点估计。** resample_0.1 / resample_0.3 的 beta 两格
   IoU 不低于所有对照为真，仅因 any-FP(M) 的点估计 0.085 > 0.05 被否。
   其余 6 格是 IoU 与对照打平或略输。
   **（§8.4 修正：按规则 P 自己的标红位置重评后，这两格也不通过了；"只卡 FP" 的说法不成立。）**
4. **full_wm 的 IoU 等于 recall。** 该场景 truth 全 1，精确率恒为 1.000，排名只反映"谁标得多"，
   不能用来比较定位精度。

## 2. 关键复核

- any-FP 只有 10 个独立值（5 方法 × 2 发射）。null_test 是同一批 400 篇，四个场景表里重复出现
  四次，不是四次独立复现；有效样本量 400，标准差约 1.1%。
- 阈值取 `rank = ceil((n+1)(1-α)) = 381` 位序统计量、严格大于，与 `frozen.json` 一致；交换性成立时
  期望误报 20/401 = 4.99%。23/400 = 5.75% 属 0.7σ 噪声；34/400 = 8.5% 与 38/400 = 9.5% 才是异常。
- **Wilson 区间在 τ 落在原子（重复取值）上时会低估不确定性。** 此时 400 篇测试文档的误报事件通过
  同一个 τ 耦合，实测误报率的方差远大于二项分布。8.5% 可能只是 1σ 以上，必须用重校准分布判定。
- 原子的来源：histogram 的 top bin [0.96, 1] 只有一个密度值 13.41，null 下 124 个位置至少一个落进
  该箱的概率是 99.4%；beta 在 cap = 25 处把 y ≳ 0.9974 压成同一密度，相应概率 27.6%；报告的
  "cap 下积分质量 0.7651" 即 23.5% 的概率质量被压平。
  **（§8.2 修正：实测的大原子在 0 而不是 τ；放大重校准方差的是 τ 自身的估计噪声。）**
- **误报膨胀跟着"估 ε"走。** 估 ε 的三条（opt_hmm / independent / fixed_rho）在 beta 上误报
  0.083–0.087，不估 ε 的两条（fixed_e / window）为 0.030–0.045。原因是边际似然在 null 文档上
  只要 mean(g) > 1 就给正 ε̂，max γ 因此混入自拟合。
- **ρ̂ 不可识别。** 关于 ρ 的信息量是状态切换次数 k，不是 token 数 n：

  | 场景 | 真值段数 | k | 真值 ρ | 观测 ρ̂ 众数 |
  |---|---:|---:|---:|---:|
  | full_wm | 1（贯穿） | 0 | ≈1.0 | 0.0（32/40，其中约 20 个是 ε̂=1 时的机械平局） |
  | switch | 1（64/124） | 2 | 0.984 | 0.95（36/40） |
  | resample_0.1 | ~7 | ~14 | 0.91 | 0.8（24/40） |
  | resample_0.3 | ~5 | ~10 | 0.83 | 0.5（22/40） |

  段长的相对标准误约 1/√k：k = 2 时 71%，k = 10 时 32%。在 7 点网格上稳定选一个 ρ，
  每格至少需要若干切换事件，这批数据在每个场景都达不到。结论是逐篇选 ρ 原则合理、当前不可识别。

## 3. 已实施的代码变更

- 规则 P 现在输出**自己的标红位置**（`gamma > fraction_tau`），与 M 的 `gamma > tau` 分开评分。
  `decide.p_labels` 提供该集合，`evaluate` 逐篇计算 `P_iou` / `P_precision` / `P_recall` / `P_f1`，
  汇总表新增 `iou_P`，报告新增 `IoU(P)` 列，`gain_P` 改用 P 自己的 IoU。
  此前 P/R/F1/IoU 全部来自 M 的位置，`gain_P` 只是换了误报门槛，不能作为 P 的证据。
- 新增 `scripts/l0_diag.py`：离线重放，输出 ① 阈值复核，② 重校准误报分布（800 篇 null 随机对半
  200 次），③ τ 处原子诊断，④ 等误报工作点曲线，⑤ argmax / marginal / 四个固定 ρ 的对比。
- 新增 `configs/text_l0_switch160.json`（test = 640，每个场景 160 篇），用于把 switch 上
  0.01 量级的 Δ 拉进可分辨范围。

## 4. 下一轮预注册修订（建议）

- **R1 误报判定改用分布口径。** any-FP 不再用 null_test 上的单点与 α 硬比较，而用"重校准后误报率
  的 95% 分位 ≤ 2α 且中位数 ≤ α"。单点 + Wilson 只作为描述。
- **R2 full_wm 移出"必须压过所有对照"。** 改为非劣检验（Δ ≥ −0.01），或单独报告为"先验代价"。
- **R3 增益判定分两步。** 先要求"vs independent 显著为正"（连续性有效），再要求"vs 三个对照非劣"
  （估计有增益）。本轮前者成立、后者不成立，混在一条判据里会丢掉这个区分。
- **R4 停止追 opt_hmm vs fixed_e。** 计划第 213 行把 0.03 IoU 定为内部实用门槛；两者差异从未接近
  该门槛，即使统计显著也不值得继续投入。
- **R5 ρ 的处理待定**，见下节。阈值 τ/q 与 frozen.json 不动。

## 5. 待定：ρ 固定在模型级还是逐篇

三个选项，代价递增：

1. **固定**：在校准集或 dev 上定一个 ρ 并冻结。零成本，但四个场景真值 ρ 从 0.83 到 1.0，必然错配。
2. **边缘化**：不再取 argmax，令 `gamma_t = Σ_ρ p(ρ|y) gamma_t(ρ)`，`p(ρ|y) ∝ exp(LL_ρ)`。保留逐篇
   自适应，同时消除 winner's curse，七个 ρ 的似然本来就算了。`l0_diag.py` 已实现该变体，可直接在
   `runs/l0full0-pos` 上比较。
3. **改模型**：用显式段长分布（HSMM）或跨文档共享 ρ 的分层先验，放到阶段 B 之后。

决策方式：用 `l0_diag.py` 的第 5 节对比 argmax / marginal / 固定值在四个场景上的 IoU 与 any-FP，
若 marginal 不低于 argmax，则采用方案 2 并登记为 R5。

## 7. 本轮未做及原因

- **block_switch（连续块替换）**：需要新增场景与编辑类型，触及 `schema.TEST_SCENARIOS`、配置校验、
  真值定义与生成流程；resample 的真值段长只有 6–11，不能代替连续性检验，但改动应当单独一轮做。
- **oracle-ε**：`detector.infer` 的契约是"只接收 Y 和 mask，永不接触真值"，把 ε_true 灌进推断会破坏
  该边界。应在生成侧另存一份"oracle 诊断"结果，而不是在检测器里开洞。
- **扩样运行**：`text_l0_switch160.json` 只是配置，尚未生成；640 篇 test 会把生成量提高到原来的 4 倍。

## 8. 离线诊断结果（`runs/l0full0-diag`，2026-11-03 下午）

输入为 `runs/l0full0-pos`，阈值取自 `runs/l0full0-eval/frozen.json`。本节修正 §1.3 与 §2 的两处说法。

### 8.1 复现校验

10 条规则重算的 τ 与 `frozen.json` 全部一致（rank 都是 381），说明重放实现与主流程一致，
后续数字不是另一套代码的产物。

### 8.2 误报门有约 42% 的先天失败率

把 800 篇 null 的 max γ 随机对半 200 次（一半定 τ、一半测误报），每条规则的分布是：

| 指标 | 范围（10 条规则） |
|---|---|
| 中位 FP | 0.0475 – 0.0500 |
| p5 | 0.0250 – 0.0300 |
| p95 | 0.0701 – 0.0801 |
| **P(FP > α)** | **0.395 – 0.445** |

也就是说，**任何一条规则，只要按正确方式重校准，实测误报超过 5% 的概率就有四成**。
"0.058 > 0.05 ⇒ 失败" 是一次抛硬币，与方法和发射无关。

beta 的 0.085 位于它自身分布的 p95（0.0801）附近，属尾部抽样而非系统漂移。三条估 ε 的 beta
规则同时偏高（0.0825 / 0.0850 / 0.0875）不是三次独立异常：它们共享同一批 null 文档，统计量
高度相关，会一起动。

### 8.3 修正 §2 的原子解释

- **τ 处没有并列**（所有规则的 τ 处原子 = 1），所以"并列导致区间偏窄"不成立。
- 最大的原子在 **0**：ε̂ = 0 时后验恒为 0，max γ 精确等于 0，占 null_cal 的 50.5%（hist）与 91.5%（beta）。
- beta 的 400 篇 null 只有 **35 个不同取值**（hist 199 个），统计量接近离散，95 分位由尾部极少数点决定。
- 重校准的标准差约 1.5%（二项分布是 1.1%），多出来的部分来自 **τ 自身的估计噪声**——这才是
  Wilson 区间低估的那一项，而不是原子。

### 8.4 规则 P 的标红不能跨方法比较

按 §3 的改动重跑评价（`runs/l0full0-eval2`），8 格中 `IoU(P)` 全部不能满足"不低于所有对照"，
`增益(P)` 全为 False。这不代表 P 更差，而是 **τ_P = 0.5 是固定值**：对 τ = 0.139 的 fixed_rho
相当于收紧，对 τ = 0.597 的 opt_hmm 相当于放松。各方法的 γ 尺度不同，固定 0.5 不是等误报工作点。

**结论：P 只能作为文档级决策规则；定位比较必须用等误报曲线。**

### 8.5 等误报工作点下 opt_hmm 的排名（diag 第 4 节）

取每条规则在 null_test 上 FPR ≤ α 的最大工作点：

| 场景 | 发射 | opt_hmm | 最优对照 | 差值 |
|---|---|---:|---|---:|
| full_wm | hist | 0.957 | window 0.996 | −0.039 |
| full_wm | beta | 0.990 | independent 0.999 | −0.009 |
| switch | hist | 0.893 | — | **最优** |
| switch | beta | 0.900 | fixed_e 0.878 | **+0.022** |
| resample_0.1 | hist | 0.774 | fixed_e 0.787 | −0.013 |
| resample_0.1 | beta | 0.794 | fixed_e 0.746 | **+0.048** |
| resample_0.3 | hist | 0.470 | fixed_e 0.502 | −0.032 |
| resample_0.3 | beta | 0.588 | fixed_e 0.470 | **+0.118** |

opt_hmm 在 4/8 格最优（两个 switch、beta 的两个 resample），在 full_wm 两格最差，在 hist 的
resample 两格居次。**"连续性在有边界的场景有优势"这条结论成立**，且 beta 上幅度明显。
这些是点估计、没有区间，需要用配对 bootstrap 补。

### 8.6 ρ 不可识别的直接证据

边缘化变体在 null_cal 上的平均 ρ 权重：

- hist：`[0.185, 0.154, 0.133, 0.130, 0.131, 0.133, 0.134]`
- beta：`[0.145, 0.143, 0.142, 0.142, 0.142, 0.143, 0.143]`（近似均匀）

权重接近均匀意味着似然分不出 ρ，这正是 §2 用 1/√k 推的"不可识别"的直接证据。

效果上两个发射方向相反：hist 上边缘化全面变好（0.964→0.983、0.786→0.814、0.486→0.524、0.895→0.897），
beta 上全面变差（0.763→0.684、0.558→0.437、0.890→0.841）。固定值也没有一个全胜：0.8 在 resample
好、switch 差；0.95 在 full_wm 与 0.3 好、0.1 差。

**R5 决定：不改估计器，主流程保持 argmax；diag 第 5 节作为 ρ 敏感性分析写进附录，不做协议变更。**
边缘化看起来"hist 变好"更可能是平均 7 个后验相当于加重平滑，而不是真的自适应。
